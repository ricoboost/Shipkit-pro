# Resend Integration

Resend provides reliable transactional email delivery with a modern developer experience and React email templates.

---

## Setup

### 1. Create Resend Account

1. Go to [resend.com](https://resend.com) and create an account
2. Verify your domain (recommended) or use Resend's test domain
3. Create an API key in the dashboard

---

### 2. Install Dependencies

```bash
npm install resend @react-email/components
```

---

### 3. Environment Variables

```bash
# .env
RESEND_API_KEY=re_xxxxx
EMAIL_FROM=noreply@your-domain.com

# Optional: for development testing
EMAIL_FROM=onboarding@resend.dev
```

## Email Service Layer

### Create Email Service

```typescript
// src/lib/email.ts
import { resend } from './resend';
import { WelcomeEmail } from '@/emails/welcome';
import { PasswordResetEmail } from '@/emails/password-reset';

const FROM = process.env.EMAIL_FROM!;

export const emailService = {
  async sendWelcome(to: string, name: string) {
    return resend.emails.send({
      from: FROM,
      to,
      subject: 'Welcome to ShipKit!',
      react: WelcomeEmail({
        name,
        loginUrl: `${process.env.NEXT_PUBLIC_APP_URL}/login`,
      }),
    });
  },

  async sendPasswordReset(to: string, token: string) {
    const resetUrl = `${process.env.NEXT_PUBLIC_APP_URL}/reset-password?token=${token}`;

    return resend.emails.send({
      from: FROM,
      to,
      subject: 'Reset Your Password',
      react: PasswordResetEmail({
        resetUrl,
        expiresIn: '1 hour',
      }),
    });
  },

  async sendVerification(to: string, code: string) {
    return resend.emails.send({
      from: FROM,
      to,
      subject: 'Verify Your Email',
      html: `<p>Your verification code is: <strong>${code}</strong></p>`,
    });
  },
};
```

## API Route Example

```typescript
// src/app/api/auth/forgot-password/route.ts
import { prisma } from '@/lib/prisma';
import { emailService } from '@/lib/email';
import { randomBytes } from 'crypto';

export async function POST(req: Request) {
  const { email } = await req.json();

  const user = await prisma.user.findUnique({ where: { email } });

  // Don't reveal if user exists
  if (!user) {
    return Response.json({ message: 'If an account exists, we sent a reset link.' });
  }

  // Generate reset token
  const token = randomBytes(32).toString('hex');
  const expires = new Date(Date.now() + 3600000); // 1 hour

  await prisma.passwordResetToken.create({
    data: { userId: user.id, token, expires },
  });

  // Send email
  await emailService.sendPasswordReset(email, token);

  return Response.json({ message: 'If an account exists, we sent a reset link.' });
}
```

## Domain Verification

### Add DNS Records

1. Go to Resend Dashboard → Domains
2. Add your domain
3. Add these DNS records:

| Type | Name | Value |
|------|------|-------|
| MX | send | feedback-smtp.us-east-1.amazonses.com |
| TXT | resend._domainkey | (provided by Resend) |
| TXT | @ | v=spf1 include:amazonses.com ~all |

4. Wait for verification (usually under 24 hours)

## Rate Limiting Emails

```typescript
import { Ratelimit } from '@upstash/ratelimit';
import { Redis } from '@upstash/redis';

const emailRateLimit = new Ratelimit({
  redis: Redis.fromEnv(),
  limiter: Ratelimit.slidingWindow(5, '1 h'), // 5 emails per hour
  prefix: 'ratelimit:email',
});

async function sendEmailWithRateLimit(to: string, options: EmailOptions) {
  const { success } = await emailRateLimit.limit(to);

  if (!success) {
    throw new Error('Email rate limit exceeded');
  }

  return resend.emails.send(options);
}
```

## Error Handling

```typescript
import { resend } from '@/lib/resend';
import * as Sentry from '@sentry/nextjs';

async function sendEmailSafely(options: EmailOptions) {
  try {
    const { data, error } = await resend.emails.send(options);

    if (error) {
      console.error('Email error:', error);
      Sentry.captureException(error);
      return { success: false, error };
    }

    return { success: true, id: data?.id };
  } catch (error) {
    console.error('Email failed:', error);
    Sentry.captureException(error);
    return { success: false, error };
  }
}
```

## Best Practices

1. **Use React Email** for consistent, maintainable templates
2. **Verify your domain** for better deliverability
3. **Don't reveal user existence** in password reset flows
4. **Rate limit** email sending to prevent abuse
5. **Log email events** for debugging and compliance
6. **Test emails** before deploying to production
