# Features 组件

功能区域帮助访问者了解您的产品的价值所在。ShipKit 包含 6 种功能组件变体,适用于不同的展示风格。

## 可用变体

| 变体 | 最适合 | 关键特性 |
|---------|----------|-------------|
| `FeaturesGrid` | 多个功能 | 响应式卡片网格 |
| `FeaturesListicle` | 详细说明 | 编号列表格式 |
| `FeaturesAccordion` | FAQ 风格内容 | 可展开部分 |
| `FeaturesTabs` | 功能类别 | 带图片的选项卡界面 |
| `FeaturesBento` | 视觉展示 | Bento 网格布局 |
| `FeaturesComparison` | 计划比较 | 并排比较 |

## 通用属性

所有功能组件共享这些基础属性:

```typescript
interface FeaturesBaseProps {
  title?: string;                   // 区域标题
  subtitle?: string;                // 标题上方的小文本
  description?: string;             // 支持文本
  animated?: boolean;               // 启用/禁用动画
  colorScheme?: ColorScheme;        // 色彩主题
  className?: string;               // 附加 CSS 类
}

interface FeatureItem {
  title: string;
  description: string;
  icon?: ReactNode;
}
```

| 尺寸 | 网格跨度 | 最适合 |
|------|-----------|----------|
| `default` | 1x1 | 标准功能 |
| `large` | 2x2 | 主打功能 |
| `wide` | 2x1 | 标题较长的功能 |
| `tall` | 1x2 | 描述较长的功能 |

### 使用方法


### 附加属性

```typescript
interface ComparisonColumn {
  name: string;
  price?: string;
  highlighted?: boolean;
  cta?: { label: string; href: string };
}

  name: string;

}

interface FeaturesComparisonProps extends FeaturesBaseProps {
  columns: ComparisonColumn[];
  features: ComparisonFeature[];
}
```

## 色彩方案

所有功能变体都支持 5 种色彩方案:

```tsx
<FeaturesGrid colorScheme="primary" {...props} />   // 默认品牌颜色
<FeaturesGrid colorScheme="secondary" {...props} /> // 柔和的次要色
<FeaturesGrid colorScheme="accent" {...props} />    // 引人注目的强调色
<FeaturesGrid colorScheme="muted" {...props} />     // 中性、柔和
<FeaturesGrid colorScheme="destructive" {...props} /> // 警告样式
```

## 动画

所有组件都包含滚动触发动画:

```tsx
// 默认启用
<FeaturesGrid animated={true} {...props} />

// 禁用以提高性能/可访问性
<FeaturesGrid animated={false} {...props} />
```

动画特性:
- **交错显示**: 项目按顺序出现
- **向上淡入**: 元素在向上移动时淡入
- **视口触发**: 滚动到视图时播放动画
