# CLI工具

ShipKit包含一套全面的CLI工具，用于优化您的开发工作流程。从初始设置到代码生成，这些工具帮助您快速推进工作。

## 快速开始

运行交互式设置向导来配置整个应用程序：

```bash
npm run setup
```

或者使用合理的默认值进行快速设置：

```bash
npm run setup:quick
```

## 可用工具

### 设置命令

逐步配置您的应用程序：

| 命令 | 描述 |
|------|------|
| `npm run setup` | 交互式设置向导 |
| `npm run setup:quick` | 使用默认值快速设置 |
| `npm run setup:stack` | Stack选择器（减少膨胀） |
| `npm run setup:env` | 配置环境变量 |
| `npm run setup:db` | 配置数据库连接 |
| `npm run setup:auth` | 配置认证提供商 |
| `npm run setup:payments` | 配置支付提供商 |
| `npm run setup:ai` | 配置AI提供商 |
| `npm run setup:admin` | 创建管理员用户 |

### 生成器命令

使用内置最佳实践生成新代码：

| 命令 | 描述 |
|------|------|
| `npm run generate:page` | 生成带i18n的新页面 |
| `npm run generate:api` | 生成新的API路由 |
| `npm run generate:component` | 生成新组件 |

### 数据库命令

管理您的数据库架构：

| 命令 | 描述 |
|------|------|
| `npm run db:generate` | 生成Prisma客户端 |
| `npm run db:push` | 将架构更改推送到数据库 |
| `npm run db:migrate` | 运行数据库迁移 |
| `npm run db:studio` | 打开Prisma Studio GUI |

## Claude Code集成

ShipKit包含Claude Code用户的斜杠命令。这些提供上下文帮助并可以执行设置任务：

- `/setup` - 完整的设置向导文档
- `/setup-env` - 环境配置指南
- `/setup-db` - 数据库设置指南
- `/setup-auth` - 认证设置指南
- `/setup-payments` - 支付设置指南
- `/setup-ai` - AI提供商设置指南
- `/create-admin` - 管理员用户创建指南
- `/scaffold-page` - 生成新页面
- `/scaffold-api` - 生成API路由
- `/scaffold-component` - 生成组件
- `/add-test` - 生成测试文件
