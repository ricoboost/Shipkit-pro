# Stack选择器

Stack选择器是一个可选的入门步骤，通过在git中忽略未使用的配置来帮助减少样板代码膨胀。您可以选择实际使用的内容，而不是保留所有AI工具配置和部署文件。

## 为什么使用它

ShipKit包含多个AI编码工具和部署策略的配置文件：

| 类别 | 文件 | 大小 |
|------|------|------|
| Claude Code | `.claude/`, `CLAUDE.md` | ~265KB |
| Cursor | `.cursor/` | ~8KB |
| Windsurf | `.windsurfrules` | ~1KB |
| Docker | `Dockerfile`, `docker-compose*.yml`, `nginx/` | ~15KB |

如果您只使用Claude Code并部署到Vercel，您可以忽略其余部分并保持项目整洁。

## 运行Stack选择器

### 交互模式

```bash
npm run setup:stack
```

这将打开一个交互式提示：

```
Stack选择器（可选）

此步骤通过忽略未使用的配置来帮助减少样板代码膨胀。
您可以跳过以保留所有选项。

您将使用哪些AI编码工具？（用逗号选择多个）
   [1] Claude Code
   [2] Cursor
   [3] Windsurf
   [a] 全部 / 保留全部（默认）
   [s] 跳过此步骤

您的选择: 1,2

您将使用哪种部署策略？
   [1] Vercel（推荐用于Next.js）
   [2] Docker / 自托管
   [s] 跳过此步骤

您的选择: 1
```

### 检查当前配置

```bash
npm run setup:stack -- --list
```

### 恢复所有文件

如果您改变主意，恢复所有被忽略的文件：

```bash
npm run setup:stack -- --restore
```

## 什么会被Git忽略

根据您的选择，Stack选择器会向您的`.gitignore`添加条目：

### AI编码工具

| 工具 | 被忽略的文件 |
|------|-------------|
| Claude Code | `.claude/`, `CLAUDE.md` |
| Cursor | `.cursor/` |
| Windsurf | `.windsurfrules` |

**注意：** 如果选择了任何AI工具，`AGENTS.md`将被保留。

### 部署策略

| 选择 | 被忽略的文件 |
|------|-------------|
| Vercel | `Dockerfile`, `docker-compose.yml`, `docker-compose.dev.yml`, `.dockerignore`, `nginx/` |
| Docker | 无（保留所有Docker文件） |

**注意：** `.github/`工作流程始终为两种策略保留。

## 配置文件

Stack选择器创建`.stack-config.json`来跟踪您的选择：

```json
{
  "selectedAt": "2024-12-13T10:30:00.000Z",
  "codingTools": ["claude", "cursor"],
  "deployment": "vercel",
  "gitignored": [
    ".windsurfrules",
    "Dockerfile",
    "docker-compose.yml",
    "docker-compose.dev.yml",
    ".dockerignore",
    "nginx/"
  ]
}
```

此文件使`--restore`命令能够正常工作。

## 与设置向导的集成

Stack选择器是运行完整设置向导时的第一个可选步骤：

```bash
npm run setup
```

向导流程是：

1. **Stack选择器**（可选）- 选择您的工具
2. 环境变量（必需）
3. 数据库（必需）
4. 认证（必需）
5. 支付（可选）
6. AI提供商（可选）
7. 管理员用户（可选）

## 最佳实践

### 何时使用Stack选择器

- 使用特定工具开始新项目
- 克隆样板后进行清理
- 减少文件浏览器中的噪音

### 何时跳过

- 评估多个AI编码工具
- 计划切换部署策略
- 在具有混合工具偏好的团队中工作

## 故障排除

### 选择后文件仍然显示

Stack选择器只将文件添加到`.gitignore` - 它不会删除它们。文件保留在您的工作目录中，但不会被提交到git。

### 想要删除文件

运行Stack选择器后，您可以手动删除被忽略的文件：

```bash
# 查看被忽略的内容
npm run setup:stack -- --list

# 如果需要，手动删除
rm -rf .cursor .windsurfrules
```

### 恢复不工作

确保`.stack-config.json`存在。如果已删除，您需要手动从`.gitignore`中删除Stack选择器部分。
