# 构建AI驱动的SaaS（带积分系统）

本教程将指导您构建一个AI驱动的SaaS应用程序，包含：

- 通过OpenRouter集成多个AI模型
- 基于积分的计费系统
- 每用户使用量跟踪

## 前提条件

- 完成[快速入门教程](/docs/tutorials/quickstart)
- [OpenRouter API密钥](https://openrouter.ai/keys)

## 配置

```bash
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-v1-xxx
```
