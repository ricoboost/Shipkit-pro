# 30分钟构建您的第一个SaaS

本教程将指导您从零开始创建一个完整功能的SaaS应用程序。

## 前提条件

- 已安装**Node.js 20+**
- **PostgreSQL**数据库
- 测试模式下的**Stripe账户**

## 步骤1：克隆和安装

```bash
git clone https://github.com/your-org/shipkit my-saas
cd my-saas
npm install
```

## 步骤2：运行设置向导

```bash
npm run setup
```

## 步骤3：配置Stripe产品

在Stripe仪表板中创建订阅产品。

## 步骤4：初始化数据库

```bash
npx prisma generate
npx prisma db push
```

## 步骤5：启动开发服务器

```bash
npm run dev
```

您的应用现在运行在[http://localhost:3000](http://localhost:3000)！
