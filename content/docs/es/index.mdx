# Bienvenido a ShipKit

ShipKit es un kit de inicio SaaS completo construido con Next.js 16, disenado para ayudarte a lanzar tu producto SaaS mas rapido con total flexibilidad.

## Por que ShipKit?

### El Problema con los Boilerplates Existentes

- Te atan a un solo proveedor de autenticacion
- Te atan a un solo proveedor de pagos
- Sin integracion de IA lista
- Documentacion estatica y desactualizada
- Lucen identicos sin personalizacion

### La Solucion ShipKit

Un starter SaaS con flexibilidad total:

- **Agnostico de Proveedores:** Cambia auth, pagos o IA con una variable de entorno
- **Nativo de IA:** Claude Code / Cursor entienden el codigo inmediatamente
- **Auto-Documentado:** Los docs se actualizan cuando cambian las funciones
- **Visualmente Personalizable:** Sistema de diseno configurado mediante UI
- **Listo para Demo:** Componentes de IA funcionales para mostrar inmediatamente

## Inicio Rapido

```bash
# Clonar el repositorio
git clone https://github.com/your-org/shipkit.git

# Instalar dependencias
npm install

# Copiar variables de entorno
cp .env.example .env

# Iniciar el servidor de desarrollo
npm run dev
```

Luego abre [http://localhost:3000](http://localhost:3000) para ver tu aplicacion.
