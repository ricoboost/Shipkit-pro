## Guía de Configuración Rápida

### Servicios Esenciales

| Servicio | Propósito | Requerido |
|----------|-----------|-----------|
| [Sentry](/docs/integrations/sentry) | Seguimiento de errores | Recomendado |
| [Resend](/docs/integrations/resend) | Entrega de emails | Requerido para auth |
| [Upstash](/docs/integrations/upstash) | Limitación de velocidad | Recomendado |
| [Analytics](/docs/integrations/analytics) | Análisis de usuarios | Opcional |
| [Almacenamiento](/docs/integrations/storage) | Carga de archivos | Opcional |

## Variables de Entorno

Añade estas a tu archivo `.env` según los servicios que uses:

```bash
# Sentry - Seguimiento de Errores
NEXT_PUBLIC_SENTRY_DSN=https://xxx@xxx.ingest.sentry.io/xxx
SENTRY_ORG=tu-org
SENTRY_PROJECT=tu-proyecto
SENTRY_AUTH_TOKEN=sntrys_xxx

# Resend - Email
RESEND_API_KEY=re_xxx
EMAIL_FROM=noreply@tu-dominio.com

# Upstash - Redis
UPSTASH_REDIS_REST_URL=https://xxx.upstash.io
UPSTASH_REDIS_REST_TOKEN=xxx

# Analytics
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
NEXT_PUBLIC_POSTHOG_KEY=phc_xxx
```
