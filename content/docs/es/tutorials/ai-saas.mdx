# Construir un SaaS Potenciado por IA con Créditos

En este tutorial, construirás una aplicación SaaS potenciada por IA que:

- Se integra con múltiples modelos de IA a través de OpenRouter
- Usa un sistema de facturación basado en créditos
- Rastrea el uso por usuario
- Implementa respuestas en streaming
- Muestra conteo de tokens en tiempo real

## Requisitos Previos

- Completado el [Tutorial de Inicio Rápido](/docs/tutorials/quickstart)
- [Clave API de OpenRouter](https://openrouter.ai/keys) (nivel gratuito disponible)

## Paso 1: Configurar OpenRouter

Añade tu clave API de OpenRouter a `.env`:

```bash
# Proveedor de IA
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-v1-xxx
```

## Paso 2: Entender el Sistema de Créditos

ShipKit incluye un sistema de créditos integrado. Así es como funciona:

### Configuración de Créditos

Edita `src/lib/payments/credits.ts`:

```typescript
export const creditConfig = {
  // Créditos por plan
  plans: {
    free: {
      monthlyCredits: 100,
      rollover: false,
    },
    pro: {
      monthlyCredits: 10000,
      rollover: true,
      maxRollover: 50000,
    },
  },

  // Costos de créditos por acción
  costs: {
    'gpt-4-turbo': 10,      // 10 créditos por solicitud
    'gpt-3.5-turbo': 1,     // 1 crédito por solicitud
    'claude-3-opus': 15,    // 15 créditos por solicitud
    'claude-3-sonnet': 5,   // 5 créditos por solicitud
  },

  // Créditos de bonificación
  signup: 100,           // Bonificación para nuevos usuarios
  referral: 500,         // Recompensa por referido
};
```

## Paso 3: Crear la API de Chat con IA

Crea una ruta API para chat de IA con seguimiento de créditos:

```typescript
// src/app/api/ai/chat/route.ts
import { auth } from '@/lib/auth';
import { openrouter } from '@/lib/ai/openrouter';
import { getCreditBalance, useCredits } from '@/lib/payments/credits';
import { creditConfig } from '@/lib/payments/credits';

export async function POST(request: Request) {
  // Autenticar usuario
  const session = await auth();
  if (!session?.user) {
    return new Response('No autorizado', { status: 401 });
  }

  const { messages, model = 'gpt-3.5-turbo' } = await request.json();

  // Verificar costo de créditos
  const creditCost = creditConfig.costs[model] || 1;
  const balance = await getCreditBalance(session.user.id);

  if (balance < creditCost) {
    return new Response(
      JSON.stringify({
        error: 'Créditos insuficientes',
        required: creditCost,
        balance,
      }),
      { status: 402, headers: { 'Content-Type': 'application/json' } }
    );
  }

  try {
    // Llamar al modelo de IA
    const response = await openrouter.chat({
      model,
      messages,
      stream: true,
    });

    // Deducir créditos
    await useCredits(
      session.user.id,
      creditCost,
      `Chat IA: ${model}`
    );

    return response;
  } catch (error) {
    console.error('Error de chat IA:', error);
    return new Response('Error del servicio de IA', { status: 500 });
  }
}
```

## Paso 4: Construir la Interfaz del Playground de IA

Crea una interfaz de chat en el panel:

```tsx
// src/components/ai/ai-playground.tsx
'use client';

import { useState } from 'react';
import { useChat } from 'ai/react';
import { Button } from '@/components/ui/button';
import { Textarea } from '@/components/ui/textarea';
import { Select } from '@/components/ui/select';

const models = [
  { id: 'gpt-3.5-turbo', name: 'GPT-3.5 Turbo', credits: 1 },
  { id: 'gpt-4-turbo', name: 'GPT-4 Turbo', credits: 10 },
  { id: 'claude-3-sonnet', name: 'Claude 3 Sonnet', credits: 5 },
  { id: 'claude-3-opus', name: 'Claude 3 Opus', credits: 15 },
];

export function AIPlayground() {
  const [model, setModel] = useState('gpt-3.5-turbo');

  const {
    messages,
    input,
    handleInputChange,
    handleSubmit,
    isLoading,
  } = useChat({
    api: '/api/ai/chat',
    body: { model },
  });

  const selectedModel = models.find((m) => m.id === model);

  return (
    <div className="flex flex-col h-[600px]">
      {/* Selector de Modelo */}
      <div className="flex items-center gap-4 mb-4">
        <Select value={model} onValueChange={setModel}>
          {models.map((m) => (
            <option key={m.id} value={m.id}>
              {m.name} ({m.credits} créditos)
            </option>
          ))}
        </Select>
        <span className="text-sm text-muted-foreground">
          Costo: {selectedModel?.credits} créditos por mensaje
        </span>
      </div>

      {/* Mensajes */}
      <div className="flex-1 overflow-y-auto p-4 space-y-4">
        {messages.map((message) => (
          <div
            key={message.id}
            className={`flex ${
              message.role === 'user' ? 'justify-end' : 'justify-start'
            }`}
          >
            <div
              className={`max-w-[80%] rounded-lg p-3 ${
                message.role === 'user'
                  ? 'bg-primary text-primary-foreground'
                  : 'bg-muted'
              }`}
            >
              <p className="whitespace-pre-wrap">{message.content}</p>
            </div>
          </div>
        ))}
      </div>

      {/* Formulario de Entrada */}
      <form onSubmit={handleSubmit} className="mt-4 flex gap-2">
        <Textarea
          value={input}
          onChange={handleInputChange}
          placeholder="Escribe tu mensaje..."
          className="flex-1"
          rows={2}
        />
        <Button type="submit" disabled={isLoading || !input.trim()}>
          Enviar
        </Button>
      </form>
    </div>
  );
}
```
