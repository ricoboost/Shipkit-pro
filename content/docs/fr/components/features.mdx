# Composants Features

Les sections de fonctionnalités aident les visiteurs à comprendre ce qui rend votre produit précieux. ShipKit inclut 6 variantes de composants de fonctionnalités pour différents styles de présentation.

## Variantes disponibles

| Variante | Idéal pour | Fonctionnalité clé |
|---------|----------|-------------|
| `FeaturesGrid` | Plusieurs fonctionnalités | Grille de cartes responsive |
| `FeaturesListicle` | Explications détaillées | Format liste numérotée |
| `FeaturesAccordion` | Contenu style FAQ | Sections extensibles |
| `FeaturesTabs` | Catégories de fonctionnalités | Interface à onglets avec images |
| `FeaturesBento` | Présentation visuelle | Disposition en grille bento |
| `FeaturesComparison` | Comparaisons de plans | Comparaison côte à côte |

## Props communes

Tous les composants de fonctionnalités partagent ces props de base :

```typescript
interface FeaturesBaseProps {
  title?: string;                   // Titre de section
  subtitle?: string;                // Petit texte au-dessus du titre
  description?: string;             // Texte de support
  animated?: boolean;               // Activer/désactiver les animations
  colorScheme?: ColorScheme;        // Thème de couleur
  className?: string;               // Classes CSS supplémentaires
}

interface FeatureItem {
  title: string;
  description: string;
  icon?: ReactNode;
}
```

### Options de taille

| Taille | Étendue de grille | Idéal pour |
|------|-----------|----------|
| `default` | 1x1 | Fonctionnalités standard |
| `large` | 2x2 | Fonctionnalités principales |
| `wide` | 2x1 | Fonctionnalités avec titres plus longs |
| `tall` | 1x2 | Fonctionnalités avec descriptions plus longues |

## FeaturesComparison

Tableau de comparaison côte à côte pour les plans ou versions de produits.

### Utilisation

```tsx
import { FeaturesComparison } from '@/components/marketing/features/features-comparison';

        { name: 'Analytics', values: [false, true, true] },
        { name: 'SSO', values: [false, false, true] },
```

### Props supplémentaires

```typescript
interface ComparisonColumn {
  name: string;
  price?: string;
  highlighted?: boolean;
  cta?: { label: string; href: string };

  name: string;
  values: (string | boolean)[];     // Booléen rendu en coche/croix
}

interface FeaturesComparisonProps extends FeaturesBaseProps {
  columns: ComparisonColumn[];
  features: ComparisonFeature[];
}
```

## Schémas de couleurs

Toutes les variantes de fonctionnalités supportent 5 schémas de couleurs :

```tsx
<FeaturesGrid colorScheme="primary" {...props} />   // Couleurs de marque par défaut
<FeaturesGrid colorScheme="secondary" {...props} /> // Secondaire subtil
<FeaturesGrid colorScheme="accent" {...props} />    // Accent accrocheur
<FeaturesGrid colorScheme="muted" {...props} />     // Neutre, atténué
<FeaturesGrid colorScheme="destructive" {...props} /> // Style avertissement
```

## Animations

Tous les composants incluent des animations déclenchées par le défilement :

```tsx
// Activé par défaut
<FeaturesGrid animated={true} {...props} />

// Désactiver pour les performances/accessibilité
<FeaturesGrid animated={false} {...props} />
```

Fonctionnalités d'animation :
- **Révélation échelonnée** : Les éléments apparaissent séquentiellement
- **Fondu vers le haut** : Les éléments apparaissent en fondu tout en se déplaçant vers le haut
- **Déclencheur de viewport** : S'anime lors du défilement dans la vue
