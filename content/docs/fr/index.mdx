# Bienvenue sur ShipKit

ShipKit est un kit de demarrage SaaS complet construit avec Next.js 16, concu pour vous aider a lancer votre produit SaaS plus rapidement avec une flexibilite totale.

## Pourquoi ShipKit ?

### Le Probleme avec les Boilerplates Existants

- Vous enferment dans un seul fournisseur d'authentification
- Vous enferment dans un seul fournisseur de paiement
- Pas d'integration IA prete a l'emploi
- Documentation statique et obsolete
- Apparence identique sans personnalisation

### La Solution ShipKit

Un starter SaaS avec une flexibilite complete :

- **Agnostique Fournisseur :** Changez auth, paiements ou IA avec une variable d'env
- **Natif IA :** Claude Code / Cursor comprennent le code immediatement
- **Auto-Documente :** Les docs se mettent a jour quand les fonctionnalites changent
- **Visuellement Personnalisable :** Systeme de design configure via UI
- **Pret pour Demo :** Composants IA fonctionnels a presenter immediatement

## Demarrage Rapide

```bash
# Cloner le depot
git clone https://github.com/your-org/shipkit.git

# Installer les dependances
npm install

# Copier les variables d'environnement
cp .env.example .env

# Demarrer le serveur de developpement
npm run dev
```

Puis ouvrez [http://localhost:3000](http://localhost:3000) pour voir votre application.
