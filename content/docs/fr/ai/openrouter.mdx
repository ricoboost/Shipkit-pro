# Configuration OpenRouter

OpenRouter fournit un accès à plusieurs modèles IA via une seule API.

## Configuration

```bash
AI_PROVIDER="openrouter"
OPENROUTER_API_KEY="sk-or-xxx"
```

## Obtenir une Clé API

1. Créer un compte sur [openrouter.ai](https://openrouter.ai)
2. Aller dans Keys
3. Créer une nouvelle clé API

## Modèles Disponibles

OpenRouter donne accès à :

- **OpenAI** : GPT-4, GPT-4 Turbo, GPT-3.5
- **Anthropic** : Claude 3 Opus, Sonnet, Haiku
- **Meta** : Llama 3 70B, 8B
- **Mistral** : Mistral Large, Medium, 7B
- **Google** : Gemini Pro, PaLM 2
- Et plus de 100 autres modèles

## Implémentation

```typescript
// src/lib/ai/openrouter.ts
export const openRouterProvider: AIProvider = {
  async chat(messages, options = {}) {
    const response = await fetch('https://openrouter.ai/api/v1/chat/completions', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${process.env.OPENROUTER_API_KEY}`,
        'Content-Type': 'application/json',
        'HTTP-Referer': process.env.NEXT_PUBLIC_APP_URL,
      },
      body: JSON.stringify({
        model: options.model || 'openai/gpt-4-turbo',
        messages,
        temperature: options.temperature ?? 0.7,
        max_tokens: options.maxTokens,
        stream: false,
      }),
    });

    const data = await response.json();
    return {
      content: data.choices[0].message.content,
      usage: data.usage,
    };
  },

  async *stream(messages, options = {}) {
    const response = await fetch('https://openrouter.ai/api/v1/chat/completions', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${process.env.OPENROUTER_API_KEY}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        model: options.model || 'openai/gpt-4-turbo',
        messages,
        stream: true,
      }),
    });

    const reader = response.body!.getReader();
    const decoder = new TextDecoder();

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      const chunk = decoder.decode(value);
      const lines = chunk.split('\n').filter(line => line.startsWith('data: '));

      for (const line of lines) {
        const data = JSON.parse(line.slice(6));
        if (data.choices[0]?.delta?.content) {
          yield data.choices[0].delta.content;
        }
      }
    }
  },
};
```
