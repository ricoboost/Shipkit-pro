## Schnelleinrichtung

### Wesentliche Dienste

| Dienst | Zweck | Erforderlich |
|--------|-------|--------------|
| [Sentry](/docs/integrations/sentry) | Fehlerverfolgung | Empfohlen |
| [Resend](/docs/integrations/resend) | E-Mail-Zustellung | Für Auth erforderlich |
| [Upstash](/docs/integrations/upstash) | Rate Limiting | Empfohlen |
| [Analytics](/docs/integrations/analytics) | Benutzeranalyse | Optional |
| [Speicher](/docs/integrations/storage) | Datei-Uploads | Optional |

## Umgebungsvariablen

Fügen Sie diese zu Ihrer `.env`-Datei hinzu:

```bash
# Sentry - Fehlerverfolgung
NEXT_PUBLIC_SENTRY_DSN=https://xxx@xxx.ingest.sentry.io/xxx
SENTRY_ORG=ihre-org
SENTRY_PROJECT=ihr-projekt
SENTRY_AUTH_TOKEN=sntrys_xxx

# Resend - E-Mail
RESEND_API_KEY=re_xxx
EMAIL_FROM=noreply@ihre-domain.com

# Upstash - Redis
UPSTASH_REDIS_REST_URL=https://xxx.upstash.io
UPSTASH_REDIS_REST_TOKEN=xxx

# Analytics
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
NEXT_PUBLIC_POSTHOG_KEY=phc_xxx
```
