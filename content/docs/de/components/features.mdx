# Features-Komponenten

Feature-Sektionen helfen Besuchern zu verstehen, was Ihr Produkt wertvoll macht. ShipKit enthält 6 Feature-Komponenten-Varianten für verschiedene Präsentationsstile.

## Verfügbare Varianten

| Variante | Geeignet für | Hauptmerkmal |
|---------|----------|-------------|
| `FeaturesGrid` | Mehrere Features | Responsives Karten-Grid |
| `FeaturesListicle` | Detaillierte Erklärungen | Nummeriertes Listenformat |
| `FeaturesAccordion` | FAQ-Style-Inhalt | Erweiterbare Sektionen |
| `FeaturesTabs` | Feature-Kategorien | Tab-Interface mit Bildern |
| `FeaturesBento` | Visuelle Präsentation | Bento-Grid-Layout |
| `FeaturesComparison` | Plan-Vergleiche | Nebeneinander-Vergleich |

## Gemeinsame Props

Alle Features-Komponenten teilen diese Basis-Props:

```typescript
interface FeaturesBaseProps {
  title?: string;                   // Sektionsüberschrift
  subtitle?: string;                // Kleiner Text über dem Titel
  description?: string;             // Unterstützender Text
  animated?: boolean;               // Animationen aktivieren/deaktivieren
  colorScheme?: ColorScheme;        // Farbthema
  className?: string;               // Zusätzliche CSS-Klassen
}

interface FeatureItem {
  title: string;
  description: string;
  icon?: ReactNode;
}
```

| Größe | Grid-Span | Geeignet für |
|------|-----------|----------|

| `wide` | 2x1 | Features mit längeren Titeln |
| `tall` | 1x2 | Features mit längeren Beschreibungen |


## Farbschemata

Alle Feature-Varianten unterstützen 5 Farbschemata:

```tsx
<FeaturesGrid colorScheme="primary" {...props} />   // Standard-Markenfarben
<FeaturesGrid colorScheme="secondary" {...props} /> // Dezenter sekundär
<FeaturesGrid colorScheme="accent" {...props} />    // Auffällige Akzente
<FeaturesGrid colorScheme="muted" {...props} />     // Neutral, gedämpft
<FeaturesGrid colorScheme="destructive" {...props} /> // Warnstil
```

## Animationen

Alle Komponenten enthalten scroll-getriggerte Animationen:

```tsx
// Standardmäßig aktiviert
<FeaturesGrid animated={true} {...props} />

// Für Leistung/Barrierefreiheit deaktivieren
<FeaturesGrid animated={false} {...props} />
```

Animationsfunktionen:
- **Gestaffelte Enthüllung**: Elemente erscheinen nacheinander
- **Fade up**: Elemente erscheinen mit Aufwärtsbewegung
- **Viewport-Trigger**: Animiert beim Scrollen in Ansicht
