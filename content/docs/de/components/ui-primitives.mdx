# UI-Primitive

ShipKit verwendet [shadcn/ui](https://ui.shadcn.com) als Grundlage für UI-Komponenten. Diese Primitive sind vollständig anpassbar und folgen den Radix UI Design-Mustern.

## Verfügbare Komponenten

Alle Komponenten befinden sich in `src/components/ui/`:

### Formular-Komponenten

| Komponente | Datei | Beschreibung |
|-----------|------|-------------|
| Button | `button.tsx` | Aktionsbuttons mit Varianten |
| Input | `input.tsx` | Texteingabefeld |
| Textarea | `textarea.tsx` | Mehrzeilige Texteingabe |
| Select | `select.tsx` | Dropdown-Auswahl |
| Checkbox | `checkbox.tsx` | Boolesche Auswahl |
| Switch | `switch.tsx` | Umschalt-Switch |
| Slider | `slider.tsx` | Bereichs-Slider |
| Label | `label.tsx` | Formularfeld-Label |

### Layout-Komponenten

| Komponente | Datei | Beschreibung |
|-----------|------|-------------|
| Card | `card.tsx` | Container mit Header/Inhalt/Footer |
| Dialog | `dialog.tsx` | Modale Dialoge |
| Alert Dialog | `alert-dialog.tsx` | Bestätigungsdialoge |
| Dropdown Menu | `dropdown-menu.tsx` | Kontextmenüs |
| Popover | `popover.tsx` | Schwebender Inhalt |
| Tabs | `tabs.tsx` | Tabbed-Inhalt |
| Scroll Area | `scroll-area.tsx` | Benutzerdefinierte Scrollbars |

| Table | `table.tsx` | Datentabellen |

### Feedback-Komponenten

## Button

Die am häufigsten verwendete Komponente mit mehreren Varianten und Größen.

### Verwendung

```tsx
import { Button } from '@/components/ui/button';

// Varianten
<Button>Standard</Button>
<Button variant="secondary">Sekundär</Button>
<Button variant="destructive">Destruktiv</Button>
<Button variant="outline">Umriss</Button>
<Button variant="ghost">Ghost</Button>
<Button variant="link">Link</Button>

// Größen
<Button size="sm">Klein</Button>
<Button size="default">Standard</Button>
<Button size="lg">Groß</Button>
<Button size="icon">
  <Icon className="h-4 w-4" />
</Button>

// Zustände
<Button disabled>Deaktiviert</Button>
<Button asChild>
  <Link href="/somewhere">Als Link</Link>
</Button>
```

### Props

```typescript
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'default' | 'destructive' | 'outline' | 'secondary' | 'ghost' | 'link';
  size?: 'default' | 'sm' | 'lg' | 'icon';
  asChild?: boolean;
}
```

## Card

Container-Komponente zum Gruppieren verwandter Inhalte.

### Verwendung

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from '@/components/ui/card';

<Card>
  <CardHeader>
    <CardTitle>Kartentitel</CardTitle>
    <CardDescription>Kartenbeschreibung oder Untertitel</CardDescription>
  </CardHeader>
  <CardContent>
    <p>Hauptinhalt kommt hier</p>
  </CardContent>
  <CardFooter>
    <Button>Aktion</Button>
  </CardFooter>
</Card>
```

## Dialog

Modaler Dialog für fokussierte Interaktionen.

### Verwendung

```tsx
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
  DialogFooter,
} from '@/components/ui/dialog';

<Dialog>
  <DialogTrigger asChild>
    <Button>Dialog öffnen</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Dialogtitel</DialogTitle>
      <DialogDescription>
        Dies ist eine Beschreibung des Dialoginhalts.
      </DialogDescription>
    </DialogHeader>
    <div className="py-4">
      Dialoginhalt kommt hier
    </div>
    <DialogFooter>
      <Button variant="outline">Abbrechen</Button>
      <Button>Bestätigen</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## Weitere Komponenten hinzufügen

ShipKit basiert auf shadcn/ui, sodass Sie einfach weitere Komponenten hinzufügen können:

```bash
npx shadcn@latest add [component-name]
```

Verfügbare Komponenten: accordion, breadcrumb, calendar, carousel, chart, collapsible, command, context-menu, drawer, form, hover-card, menubar, navigation-menu, pagination, radio-group, resizable, sheet, skeleton, tooltip und mehr.

Siehe die [shadcn/ui-Dokumentation](https://ui.shadcn.com/docs/components) für die vollständige Liste.

## Anpassung

Alle Komponenten verwenden CSS-Variablen für das Theming. Passen Sie sie in Ihrer `globals.css` an:

```css
:root {
  --primary: 222.2 47.4% 11.2%;
  --primary-foreground: 210 40% 98%;
  --secondary: 210 40% 96.1%;
  --secondary-foreground: 222.2 47.4% 11.2%;
  /* ... */
}

.dark {
  --primary: 210 40% 98%;
  --primary-foreground: 222.2 47.4% 11.2%;
  /* ... */
}
```

Oder verwenden Sie den [Theme Builder](/docs/components/theme-builder) für visuelle Anpassung.
