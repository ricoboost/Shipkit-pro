# Willkommen bei ShipKit

ShipKit ist ein umfassendes SaaS-Starter-Kit, das mit Next.js 16 entwickelt wurde und Ihnen hilft, Ihr SaaS-Produkt schneller mit vollstaendiger Flexibilitaet zu starten.

## Warum ShipKit?

### Das Problem mit bestehenden Boilerplates

- Binden Sie an einen einzigen Auth-Provider
- Binden Sie an einen einzigen Payment-Provider
- Keine fertige KI-Integration
- Statische und veraltete Dokumentation
- Sehen identisch aus ohne Anpassung

### Die ShipKit-Loesung

Ein SaaS-Starter mit vollstaendiger Flexibilitaet:

- **Provider-Agnostisch:** Wechseln Sie Auth, Payments oder KI mit einer Env-Variable
- **KI-Nativ:** Claude Code / Cursor verstehen die Codebasis sofort
- **Selbst-Dokumentierend:** Docs aktualisieren sich wenn Features aendern
- **Visuell Anpassbar:** Design-System ueber UI konfiguriert
- **Demo-Bereit:** Funktionierende KI-Komponenten sofort praesentierbar

## Schnellstart

```bash
# Repository klonen
git clone https://github.com/your-org/shipkit.git

# Abhaengigkeiten installieren
npm install

# Umgebungsvariablen kopieren
cp .env.example .env

# Entwicklungsserver starten
npm run dev
```

Oeffnen Sie dann [http://localhost:3000](http://localhost:3000) um Ihre App zu sehen.
