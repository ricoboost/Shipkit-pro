# Construa Seu Primeiro SaaS em 30 Minutos

Neste tutorial, você criará uma aplicação SaaS totalmente funcional do zero.

## Pré-requisitos

- **Node.js 20+** instalado
- Banco de dados **PostgreSQL**
- **Conta Stripe** em modo de teste

## Passo 1: Clonar e Instalar

```bash
git clone https://github.com/your-org/shipkit meu-saas
cd meu-saas
npm install
```

## Passo 2: Executar o Assistente de Configuração

```bash
npm run setup
```

## Passo 3: Configurar Produtos Stripe

Crie seus produtos de assinatura no Dashboard do Stripe.

## Passo 4: Inicializar o Banco de Dados

```bash
npx prisma generate
npx prisma db push
```

## Passo 5: Iniciar o Servidor de Desenvolvimento

```bash
npm run dev
```
