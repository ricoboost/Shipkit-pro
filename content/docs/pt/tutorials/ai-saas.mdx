# Construir um SaaS Alimentado por IA com Créditos

Neste tutorial, você construirá uma aplicação SaaS alimentada por IA com:

- Integração com múltiplos modelos de IA via OpenRouter
- Sistema de cobrança baseado em créditos
- Rastreamento de uso por usuário

## Pré-requisitos

- [Tutorial de Início Rápido](/docs/tutorials/quickstart) concluído
- [Chave API OpenRouter](https://openrouter.ai/keys)

## Configuração

```bash
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-v1-xxx
```
