# Logo Cloud Components

Social proof through partner and client logos. These components help establish credibility by showcasing the companies you work with.

## Components Overview

| Component | Purpose | Best For |
|-----------|---------|----------|
| `LogoCloud` | Static grid of logos | Clean, professional display |
| `LogoMarquee` | Infinite scrolling logos | Dynamic, space-efficient |
| `LogoShowcase` | Rich cards with details | Partner highlights, integrations |

## Logo Cloud

A clean, responsive grid of logos perfect for "Trusted by" sections.

### Preview

<ComponentPreview title="Logo Cloud" background="muted">
  <LogoCloudPreview />
</ComponentPreview>

### Usage

```tsx
import { LogoCloud } from '@/components/marketing/logos/logo-cloud';

<LogoCloud
  title="Trusted by Industry Leaders"
  subtitle="Join thousands of companies"
  logos={[
    { name: "Vercel", src: "/logos/vercel.svg", href: "https://vercel.com" },
    { name: "Stripe", src: "/logos/stripe.svg", href: "https://stripe.com" },
    { name: "GitHub", src: "/logos/github.svg", href: "https://github.com" },
    { name: "Shopify", src: "/logos/shopify.svg" },
    { name: "Slack", src: "/logos/slack.svg" },
    { name: "Notion", src: "/logos/notion.svg" }
  ]}
  columns={6}
  variant="grayscale"
/>
```

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | - | Section heading |
| `subtitle` | `string` | - | Small text above title |
| `logos` | `Logo[]` | Required | Array of logo items |
| `variant` | `'default' \| 'grayscale' \| 'bordered'` | `'default'` | Visual style |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Logo size preset |
| `columns` | `3 \| 4 \| 5 \| 6` | `6` | Number of columns |
| `animated` | `boolean` | `true` | Enable animations |
| `colorScheme` | `string` | `'primary'` | Color variant |

### Logo Interface

```tsx
interface Logo {
  name: string;         // Alt text and aria-label
  src: string;          // Image path
  href?: string;        // Optional link
  width?: number;       // Custom width (overrides size)
  height?: number;      // Custom height (overrides size)
}
```

### Variants

- **default** - Full color logos
- **grayscale** - Muted grayscale, color on hover
- **bordered** - Logos in bordered cards

## Logo Marquee

Infinitely scrolling logo banner for a dynamic, space-efficient display.

### Preview

<ComponentPreview title="Logo Marquee" background="muted">
  <LogoMarqueePreview />
</ComponentPreview>

### Usage

```tsx
import { LogoMarquee } from '@/components/marketing/logos/logo-marquee';

<LogoMarquee
  title="Powering teams at"
  logos={[
    { name: "Vercel", src: "/logos/vercel.svg" },
    { name: "Stripe", src: "/logos/stripe.svg" },
    { name: "GitHub", src: "/logos/github.svg" },
    { name: "Shopify", src: "/logos/shopify.svg" },
    { name: "Slack", src: "/logos/slack.svg" },
    { name: "Notion", src: "/logos/notion.svg" },
    { name: "Linear", src: "/logos/linear.svg" },
    { name: "Figma", src: "/logos/figma.svg" }
  ]}
  speed="normal"
  direction="left"
  pauseOnHover
  variant="grayscale"
/>
```

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | - | Section heading |
| `subtitle` | `string` | - | Small text above title |
| `logos` | `MarqueeLogo[]` | Required | Array of logos |
| `speed` | `'slow' \| 'normal' \| 'fast'` | `'normal'` | Animation speed |
| `direction` | `'left' \| 'right'` | `'left'` | Scroll direction |
| `pauseOnHover` | `boolean` | `true` | Pause animation on hover |
| `variant` | `'default' \| 'grayscale'` | `'default'` | Visual style |
| `colorScheme` | `string` | `'primary'` | Color variant |

### Speed Values

| Speed | Duration |
|-------|----------|
| `slow` | 60 seconds |
| `normal` | 40 seconds |
| `fast` | 20 seconds |

<Callout type="info">
The marquee duplicates logos automatically for seamless infinite scrolling. Provide at least 6-8 logos for best results.
</Callout>

## Best Practices

1. **Optimize Images**: Use SVG for crisp logos at any size
2. **Get Permission**: Ensure you have rights to display logos
3. **Consistent Sizing**: Use similar aspect ratios for visual balance
4. **Grayscale Works**: Muted logos look professional and don't distract
5. **Limit Count**: 6-12 logos is ideal; too many reduces impact
6. **Meaningful Selection**: Choose recognizable brands when possible

## Creating Logo Assets

For best results:

```
/public/logos/
├── company-name.svg    # Horizontal logo, ~140x40
├── company-name-dark.svg   # Optional dark mode version
```

Recommended specifications:
- Format: SVG (preferred) or PNG with transparency
- Size: 140-200px width for horizontal logos
- Aspect ratio: Keep consistent across all logos
- Background: Transparent

## Accessibility

- All logos have `alt` attributes from `name` prop
- Links have `aria-label` for screen readers
- Animations can be paused
- Color contrast maintained in all variants
