# Componentes de Recursos

As seções de recursos ajudam os visitantes a entender o que torna seu produto valioso. O ShipKit inclui 6 variantes de componentes de recursos para diferentes estilos de apresentação.

## Variantes Disponíveis

| Variante | Melhor Para | Recurso Principal |
|---------|----------|-------------|
| `FeaturesGrid` | Múltiplos recursos | Grade de cartões responsiva |
| `FeaturesListicle` | Explicações detalhadas | Formato de lista numerada |
| `FeaturesAccordion` | Conteúdo estilo FAQ | Seções expansíveis |
| `FeaturesTabs` | Categorias de recursos | Interface com abas e imagens |
| `FeaturesBento` | Vitrine visual | Layout em grade bento |
| `FeaturesComparison` | Comparações de planos | Comparação lado a lado |

## Props Comuns

Todos os componentes de recursos compartilham estas props base:

```typescript
interface FeaturesBaseProps {
  title?: string;                   // Título da seção
  subtitle?: string;                // Texto pequeno acima do título
  description?: string;             // Texto de apoio
  animated?: boolean;               // Ativar/desativar animações
  colorScheme?: ColorScheme;        // Tema de cores
  className?: string;               // Classes CSS adicionais
}

interface FeatureItem {
  title: string;
  description: string;
  icon?: ReactNode;
}
```

### Props Adicionais

```typescript
interface BentoItem {
  title: string;
  description: string;
  icon?: ReactNode;
  size?: 'default' | 'large' | 'wide' | 'tall';
}

interface FeaturesBentoProps extends FeaturesBaseProps {
  items: BentoItem[];
}
```

### Opções de Tamanho

| Tamanho | Extensão da Grade | Melhor Para |
|------|-----------|----------|
| `default` | 1x1 | Recursos padrão |
| `large` | 2x2 | Recursos principais |
| `wide` | 2x1 | Recursos com títulos mais longos |
| `tall` | 1x2 | Recursos com descrições mais longas |

## FeaturesComparison

Tabela de comparação lado a lado para planos ou versões de produtos.

### Uso

```tsx
import { FeaturesComparison } from '@/components/marketing/features/features-comparison';

export function PlanComparison() {
  return (
    <FeaturesComparison
      title="Compare os Planos"
      columns={[
        { name: 'Iniciante', price: 'Grátis' },
        { name: 'Pro', price: 'R$19/mês', highlighted: true },
        { name: 'Enterprise', price: 'Personalizado' },
      ]}
      features={[
        { name: 'Usuários', values: ['1', 'Ilimitado', 'Ilimitado'] },
        { name: 'Chamadas API', values: ['1.000/mês', '100.000/mês', 'Ilimitado'] },
        { name: 'Suporte', values: ['Comunidade', 'Prioritário', '24/7 Dedicado'] },
        { name: 'Domínio Personalizado', values: [false, true, true] },
        { name: 'Analytics', values: [false, true, true] },
        { name: 'SSO', values: [false, false, true] },
      ]}
    />
  );
}
```

### Props Adicionais

```typescript
interface ComparisonColumn {
  name: string;
  price?: string;
  highlighted?: boolean;
  cta?: { label: string; href: string };
}

interface ComparisonFeature {
  name: string;
  values: (string | boolean)[];     // Boolean renderiza como check/x
}

interface FeaturesComparisonProps extends FeaturesBaseProps {
  columns: ComparisonColumn[];
  features: ComparisonFeature[];
}
```

## Esquemas de Cores

Todas as variantes de recursos suportam 5 esquemas de cores:

```tsx
<FeaturesGrid colorScheme="primary" {...props} />   // Cores de marca padrão
<FeaturesGrid colorScheme="secondary" {...props} /> // Secundário sutil
<FeaturesGrid colorScheme="accent" {...props} />    // Destaque chamativo
<FeaturesGrid colorScheme="muted" {...props} />     // Neutro, discreto
<FeaturesGrid colorScheme="destructive" {...props} /> // Estilo de aviso
```

## Animações

Todos os componentes incluem animações acionadas por rolagem:

```tsx
// Ativado por padrão
<FeaturesGrid animated={true} {...props} />

// Desativar para desempenho/acessibilidade
<FeaturesGrid animated={false} {...props} />
```

Recursos de animação:
- **Revelação escalonada**: Itens aparecem sequencialmente
- **Fade up**: Elementos aparecem enquanto sobem
- **Gatilho de viewport**: Anima quando rolado para a visualização
