# Visão Geral dos Componentes

O ShipKit inclui uma biblioteca abrangente de componentes pré-construídos e personalizáveis projetados para aplicações SaaS modernas. Todos os componentes suportam:

- **Esquemas de Cores**: `primary`, `secondary`, `accent`, `muted`, `destructive`
- **Animações**: Animações opcionais com Framer Motion
- **Design Responsivo**: Mobile-first, totalmente responsivo
- **TypeScript**: Segurança de tipos completa com interfaces exportadas

## Primitivos de UI

O ShipKit usa [shadcn/ui](https://ui.shadcn.com) como base para componentes de UI. Todos os primitivos são totalmente personalizáveis e seguem os padrões de design do Radix UI.

Consulte a documentação de [Primitivos de UI](/docs/components/ui-primitives) para a lista completa.

## Padrões de Importação

### Componentes de Marketing

```tsx
import { HeroCentered } from '@/components/marketing/hero/hero-centered';
import { CTASimple } from '@/components/marketing/cta/cta-simple';
import { FeaturesGrid } from '@/components/marketing/features/features-grid';
```

### Primitivos de UI

```tsx
import { Button } from '@/components/ui/button';
import { Card, CardHeader, CardContent } from '@/components/ui/card';
import { Input } from '@/components/ui/input';
```

## Tipos Compartilhados

Todos os componentes de marketing compartilham tipos comuns definidos em `@/components/marketing/types`:

```typescript
export type ColorScheme = 'primary' | 'secondary' | 'accent' | 'muted' | 'destructive';

export interface CTAButton {
  label: string;
  href: string;
  variant?: 'default' | 'outline' | 'ghost';
}

export interface BaseMarketingProps {
  className?: string;
  colorScheme?: ColorScheme;
}

export interface FeatureItem {
  title: string;
  description: string;
  icon?: ReactNode;
}
```

## Início Rápido

Veja como construir uma página de destino completa:

```tsx
import { HeroCentered } from '@/components/marketing/hero/hero-centered';
import { FeaturesGrid } from '@/components/marketing/features/features-grid';
import { CTASimple } from '@/components/marketing/cta/cta-simple';
import { Zap, Shield, Rocket } from 'lucide-react';

export default function LandingPage() {
  return (
    <>
      <HeroCentered
        title="Construa Produtos SaaS Mais Rápido"
        description="O kit inicial completo para aplicações web modernas"
        primaryCTA={{ label: 'Começar', href: '/register' }}
        secondaryCTA={{ label: 'Ver Demo', href: '/demo' }}
        badge="Agora em v3.0"
      />

      <FeaturesGrid
        title="Tudo o Que Você Precisa"
        features={[
          { title: 'Rápido', description: 'Construído para velocidade', icon: <Zap /> },
          { title: 'Seguro', description: 'Segurança empresarial', icon: <Shield /> },
          { title: 'Escalável', description: 'Cresce com você', icon: <Rocket /> },
        ]}
      />

      <CTASimple
        title="Pronto para Começar?"
        description="Junte-se a milhares de desenvolvedores construindo com ShipKit"
        primaryCTA={{ label: 'Iniciar Teste Gratuito', href: '/register' }}
      />
    </>
  );
}
```
