# Theme Builder

O componente Theme Builder fornece uma interface visual para personalizar as cores do tema da sua aplicação, com visualização ao vivo e capacidades de exportação de CSS.

## Visão Geral

Recursos principais:
- **5 Predefinições Pré-construídas**: Comece com um esquema de cores profissionalmente projetado
- **Seletor de Cores HSL**: Ajuste fino de qualquer cor com controles de Matiz, Saturação e Luminosidade
- **Modo Claro/Escuro**: Personalize cores para ambos os modos independentemente
- **Visualização ao Vivo**: Veja mudanças instantaneamente com componentes de visualização
- **Exportação CSS**: Baixe seu tema personalizado como CSS

## Uso

### Implementação Básica

```tsx
import { ThemeBuilder } from '@/components/theme/theme-builder';

export default function ThemeSettingsPage() {
  return (
    <div className="container py-8">
      <h1 className="text-3xl font-bold mb-8">Personalizar Tema</h1>
      <ThemeBuilder />
    </div>
  );
}
```

O Theme Builder também está disponível no dashboard admin em `/admin/theme`.

## Predefinições de Tema

Cinco predefinições profissionalmente projetadas estão incluídas:

| Predefinição | Cor Primária | Estilo |
|--------|---------------|-------|
| Default | Roxo | Moderno, neutro |
| Ocean | Azul | Profissional, calmo |
| Forest | Verde | Natural, orgânico |
| Sunset | Laranja | Quente, energético |
| Midnight | Azul Profundo | Escuro, elegante |

### Selecionando uma Predefinição

As predefinições servem como pontos de partida. Clique em qualquer cartão de predefinição para aplicá-la, depois personalize cores individuais conforme necessário.

```tsx
// Predefinições são definidas em src/lib/theme.ts
export const themePresets = {
  default: {
    name: 'Default',
    light: { primary: '262 83% 58%', /* ... */ },
    dark: { primary: '263 70% 50%', /* ... */ },
    radius: '0.5rem',
  },
  ocean: { /* ... */ },
  forest: { /* ... */ },
  sunset: { /* ... */ },
  midnight: { /* ... */ },
};
```

## Grupos de Cores

As cores são organizadas em quatro grupos:

### Cores Base
- `background` - Fundo da página
- `foreground` - Cor do texto primário
- `card` - Fundos de cartões
- `cardForeground` - Texto em cartões

### Primária e Secundária
- `primary` - Cor de marca principal
- `primaryForeground` - Texto em fundos primários
- `secondary` - Cor de marca secundária
- `secondaryForeground` - Texto em fundos secundários

### Elementos de UI
- `muted` - Fundos discretos
- `mutedForeground` - Texto discreto
- `accent` - Destaques de destaque
- `accentForeground` - Texto em destaques

### Feedback e Bordas
- `destructive` - Cor de erro/perigo
- `destructiveForeground` - Texto em destrutivo
- `border` - Cor da borda
- `input` - Cor da borda de entrada
- `ring` - Cor do anel de foco

## Seletor de Cores HSL

Cada cor é controlada com controles deslizantes HSL (Matiz, Saturação, Luminosidade):

| Controle | Intervalo | Descrição |
|--------|-------|-------------|
| H (Matiz) | 0-360 | A cor base (vermelho=0, verde=120, azul=240) |
| S (Saturação) | 0-100% | Intensidade da cor (0=cinza, 100=vívido) |
| L (Luminosidade) | 0-100% | Brilho (0=preto, 50=puro, 100=branco) |

### Por Que HSL?

HSL facilita a criação de paletas de cores consistentes:
- Mantenha a mesma **Matiz** para consistência de cor
- Ajuste a **Saturação** para intensidade
- Ajuste a **Luminosidade** para contraste (cores de primeiro plano geralmente são extremos opostos)

## Raio de Borda

Controle a arredondamento dos elementos de UI globalmente:

| Valor | Estilo | Melhor Para |
|-------|-------|----------|
| 0rem | Cantos afiados | Minimalista, moderno |
| 0.25rem | Arredondamento sutil | Profissional |
| 0.5rem | Arredondamento moderado | Equilibrado (padrão) |
| 0.75rem | Mais arredondado | Amigável |
| 1rem+ | Muito arredondado | Brincalhão, suave |

## Visualização ao Vivo

O painel de visualização mostra:
- **Botões**: Todas as variantes (primário, secundário, contorno, destrutivo)
- **Badges**: Diferentes estilos de badge
- **Seção Discreta**: Texto em fundos discretos
- **Cartões Aninhados**: Aparência de cartão sobre cartão

Use isso para verificar contraste e harmonia visual antes de exportar.

## Exportando Seu Tema

Clique em **Exportar CSS** para baixar seu tema personalizado:

```css
/* theme.css gerado */
:root {
  --background: 0 0% 100%;
  --foreground: 222.2 84% 4.9%;
  --card: 0 0% 100%;
  --card-foreground: 222.2 84% 4.9%;
  --primary: 262 83% 58%;
  --primary-foreground: 210 40% 98%;
  /* ... todas as cores */
  --radius: 0.5rem;
}

.dark {
  --background: 222.2 84% 4.9%;
  --foreground: 210 40% 98%;
  /* ... cores do modo escuro */
}
```

### Aplicando Tema Exportado

1. Copie o CSS exportado para seu `src/app/globals.css`
2. Substitua as variáveis de cor `:root` e `.dark` existentes
3. O tema será aplicado automaticamente

## Persistência de Tema

Temas são salvos no localStorage automaticamente:

```typescript
// Seleção de tema é persistida
const saved = getSavedTheme();  // Retorna nome da predefinição ou 'default'

// Salvamento manual
saveTheme('ocean');

// Aplicar tema
applyTheme(themeConfig);
```

## Uso Programático

Você também pode usar os utilitários de tema diretamente:

```tsx
import {
  themePresets,
  applyTheme,
  saveTheme,
  getSavedTheme,
  exportThemeCSS,
  type ThemeConfig,
} from '@/lib/theme';

// Aplicar uma predefinição
applyTheme(themePresets.ocean);

// Salvar preferência do usuário
saveTheme('ocean');

// Obter CSS para implementação personalizada
const css = exportThemeCSS(customTheme);
```

## Carregamento de Tema no Servidor

Para SSR, use o componente `ServerThemeLoader` para evitar flash de conteúdo sem estilo:

```tsx
// No seu layout raiz
import { ServerThemeLoader } from '@/components/theme/server-theme-loader';

export default function RootLayout({ children }) {
  return (
    <html lang="pt">
      <head>
        <ServerThemeLoader />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

Isso injeta um script que aplica o tema salvo antes da página renderizar.

## Melhores Práticas

### Proporções de Contraste
Garanta contraste suficiente entre cores de primeiro plano e fundo:
- **Texto normal**: Proporção mínima de contraste 4.5:1
- **Texto grande**: Proporção mínima de contraste 3:1

### Considerações de Modo Escuro
- Não apenas inverta as cores - modo escuro precisa de níveis de saturação diferentes
- Reduza ligeiramente a saturação para fundos escuros
- Garanta que as bordas permaneçam visíveis

### Consistência de Marca
- Use a cor primária da sua marca para a variável `primary`
- Mantenha `secondary` e `accent` complementares
- Teste com conteúdo real, não apenas a visualização
