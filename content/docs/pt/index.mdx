## Por que ShipKit?

### O Problema com Boilerplates Existentes

- Prendem voce a um unico provedor de autenticacao
- Prendem voce a um unico provedor de pagamento
- Sem integracao de IA pronta
- Documentacao estatica e desatualizada
- Parecem identicos sem personalizacao

### A Solucao ShipKit

Um starter SaaS com flexibilidade total:

- **Agnostico de Provedores:** Troque auth, pagamentos ou IA com uma variavel de ambiente
- **Nativo de IA:** Claude Code / Cursor entendem o codigo imediatamente
- **Auto-Documentado:** Docs se atualizam quando os recursos mudam
- **Visualmente Personalizavel:** Sistema de design configurado via UI
- **Pronto para Demo:** Componentes de IA funcionais para demonstrar imediatamente

## Inicio Rapido

```bash
# Clonar o repositorio
git clone https://github.com/your-org/shipkit.git

# Instalar dependencias
npm install

# Copiar variaveis de ambiente
cp .env.example .env

# Iniciar o servidor de desenvolvimento
npm run dev
```

Depois abra [http://localhost:3000](http://localhost:3000) para ver seu app.
