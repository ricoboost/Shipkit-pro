# CI/CD Pipeline

ShipKit includes a pre-configured GitHub Actions workflow for continuous integration and deployment.

## Features

- Automated testing on every push and PR
- Linting and type checking
- Build verification
- Parallel job execution
- Caching for faster builds
- Optional deployment triggers

## Workflow File

The CI/CD pipeline is defined in `.github/workflows/ci.yml`:

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm run lint

  type-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm run type-check

  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm run test:run

  e2e:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npx playwright install --with-deps
      - run: npm run build
      - run: npm run test:e2e

  build:
    runs-on: ubuntu-latest
    needs: [lint, type-check, test]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm run build
```

## Jobs Explained

### Lint

Runs ESLint to check for code style issues and potential errors:

```bash
npm run lint
```

### Type Check

Verifies TypeScript types without emitting files:

```bash
npm run type-check
# or: tsc --noEmit
```

### Test

Runs unit tests with Vitest:

```bash
npm run test:run
```

### E2E

Runs end-to-end tests with Playwright:

```bash
npm run test:e2e
```

### Build

Creates a production build to verify everything compiles:

```bash
npm run build
```

## Required Scripts

Add these scripts to your `package.json`:

```json
{
  "scripts": {
    "lint": "next lint",
    "type-check": "tsc --noEmit",
    "test": "vitest",
    "test:run": "vitest run",
    "test:e2e": "playwright test",
    "build": "next build"
  }
}
```

## Deployment

### Vercel (Recommended)

ShipKit works seamlessly with Vercel's automatic deployments:

1. Connect your GitHub repository to Vercel
2. Vercel automatically deploys on push to `main`
3. Preview deployments for pull requests

### Custom Deployment

Add a deployment job to the workflow:

```yaml
deploy:
  runs-on: ubuntu-latest
  needs: [build]
  if: github.ref == 'refs/heads/main'
  steps:
    - uses: actions/checkout@v4
    # Add your deployment steps here
```

## Environment Variables

Set secrets in GitHub repository settings:

1. Go to Settings > Secrets and variables > Actions
2. Add required secrets:
   - `DATABASE_URL`
   - `NEXTAUTH_SECRET`
   - `STRIPE_SECRET_KEY`
   - etc.

Use in workflow:

```yaml
env:
  DATABASE_URL: ${{ secrets.DATABASE_URL }}
```

## Caching

The workflow uses Node.js caching for faster builds:

```yaml
- uses: actions/setup-node@v4
  with:
    node-version: '20'
    cache: 'npm'
```

## Branch Protection

Recommended branch protection rules for `main`:

1. Require pull request reviews
2. Require status checks to pass:
   - `lint`
   - `type-check`
   - `test`
   - `build`
3. Require branches to be up to date

## Customization

### Running Jobs Sequentially

```yaml
build:
  needs: [lint, type-check, test]
```

### Matrix Builds

Test across multiple Node versions:

```yaml
test:
  strategy:
    matrix:
      node-version: [18, 20, 22]
  steps:
    - uses: actions/setup-node@v4
      with:
        node-version: ${{ matrix.node-version }}
```

### Conditional Jobs

```yaml
deploy:
  if: github.event_name == 'push' && github.ref == 'refs/heads/main'
```
