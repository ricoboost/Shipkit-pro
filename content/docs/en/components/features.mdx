# Features Components

Feature sections help visitors understand what makes your product valuable. ShipKit includes 6 feature component variants for different presentation styles.

## Available Variants

| Variant | Best For | Key Feature |
|---------|----------|-------------|
| `FeaturesGrid` | Multiple features | Responsive card grid |
| `FeaturesListicle` | Detailed explanations | Numbered list format |
| `FeaturesAccordion` | FAQ-style content | Expandable sections |
| `FeaturesTabs` | Feature categories | Tabbed interface with images |
| `FeaturesBento` | Visual showcase | Bento grid layout |
| `FeaturesComparison` | Plan comparisons | Side-by-side comparison |

## Common Props

All features components share these base props:

```typescript
interface FeaturesBaseProps {
  title?: string;                   // Section heading
  subtitle?: string;                // Small text above title
  description?: string;             // Supporting text
  animated?: boolean;               // Enable/disable animations
  colorScheme?: ColorScheme;        // Color theme
  className?: string;               // Additional CSS classes
}

interface FeatureItem {
  title: string;
  description: string;
  icon?: ReactNode;
}
```

### Size Options

| Size | Grid Span | Best For |
|------|-----------|----------|
| `default` | 1x1 | Standard features |
| `large` | 2x2 | Hero features |
| `wide` | 2x1 | Features with longer titles |
| `tall` | 1x2 | Features with longer descriptions |

## FeaturesComparison

Side-by-side comparison table for plans or product versions.

### Usage

```tsx
import { FeaturesComparison } from '@/components/marketing/features/features-comparison';

export function PlanComparison() {
  return (
    <FeaturesComparison
      title="Compare Plans"
      columns={[
        { name: 'Starter', price: 'Free' },
        { name: 'Pro', price: '$19/mo', highlighted: true },
        { name: 'Enterprise', price: 'Custom' },
      ]}
      features={[
        { name: 'Users', values: ['1', 'Unlimited', 'Unlimited'] },
        { name: 'API Calls', values: ['1,000/mo', '100,000/mo', 'Unlimited'] },
        { name: 'Support', values: ['Community', 'Priority', '24/7 Dedicated'] },
        { name: 'Custom Domain', values: [false, true, true] },
        { name: 'Analytics', values: [false, true, true] },
        { name: 'SSO', values: [false, false, true] },
      ]}
    />
  );
}
```

### Additional Props

```typescript
interface ComparisonColumn {
  name: string;
  price?: string;
  highlighted?: boolean;
  cta?: { label: string; href: string };
}

interface ComparisonFeature {
  name: string;
  values: (string | boolean)[];     // Boolean renders as check/x
}

interface FeaturesComparisonProps extends FeaturesBaseProps {
  columns: ComparisonColumn[];
  features: ComparisonFeature[];
}
```

## Color Schemes

All feature variants support 5 color schemes:

```tsx
<FeaturesGrid colorScheme="primary" {...props} />   // Default brand colors
<FeaturesGrid colorScheme="secondary" {...props} /> // Subtle secondary
<FeaturesGrid colorScheme="accent" {...props} />    // Eye-catching accent
<FeaturesGrid colorScheme="muted" {...props} />     // Neutral, subdued
<FeaturesGrid colorScheme="destructive" {...props} /> // Warning style
```

## Animations

All components include scroll-triggered animations:

```tsx
// Enabled by default
<FeaturesGrid animated={true} {...props} />

// Disable for performance/accessibility
<FeaturesGrid animated={false} {...props} />
```

Animation features:
- **Staggered reveal**: Items appear sequentially
- **Fade up**: Elements fade in while moving up
- **Viewport trigger**: Animates when scrolled into view
