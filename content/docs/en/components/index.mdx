# Components Overview

ShipKit includes a comprehensive library of pre-built, customizable components designed for modern SaaS applications. All components support:

- **Color Schemes**: `primary`, `secondary`, `accent`, `muted`, `destructive`
- **Animations**: Optional Framer Motion animations
- **Responsive Design**: Mobile-first, fully responsive
- **TypeScript**: Full type safety with exported interfaces

## UI Primitives

ShipKit uses [shadcn/ui](https://ui.shadcn.com) as the foundation for UI components. All primitives are fully customizable and follow the Radix UI design patterns.

See the [UI Primitives](/docs/components/ui-primitives) documentation for the complete list.

## Import Patterns

### Marketing Components

```tsx
import { HeroCentered } from '@/components/marketing/hero/hero-centered';
import { CTASimple } from '@/components/marketing/cta/cta-simple';
import { FeaturesGrid } from '@/components/marketing/features/features-grid';
```

### UI Primitives

```tsx
import { Button } from '@/components/ui/button';
import { Card, CardHeader, CardContent } from '@/components/ui/card';
import { Input } from '@/components/ui/input';
```

## Shared Types

All marketing components share common types defined in `@/components/marketing/types`:

```typescript
export type ColorScheme = 'primary' | 'secondary' | 'accent' | 'muted' | 'destructive';

export interface CTAButton {
  label: string;
  href: string;
  variant?: 'default' | 'outline' | 'ghost';
}

export interface BaseMarketingProps {
  className?: string;
  colorScheme?: ColorScheme;
}

export interface FeatureItem {
  title: string;
  description: string;
  icon?: ReactNode;
}
```

## Quick Start

Here's how to build a complete landing page:

```tsx
import { HeroCentered } from '@/components/marketing/hero/hero-centered';
import { FeaturesGrid } from '@/components/marketing/features/features-grid';
import { CTASimple } from '@/components/marketing/cta/cta-simple';
import { Zap, Shield, Rocket } from 'lucide-react';

export default function LandingPage() {
  return (
    <>
      <HeroCentered
        title="Build SaaS Products Faster"
        description="The complete starter kit for modern web applications"
        primaryCTA={{ label: 'Get Started', href: '/register' }}
        secondaryCTA={{ label: 'View Demo', href: '/demo' }}
        badge="Now in v3.0"
      />

      <FeaturesGrid
        title="Everything You Need"
        features={[
          { title: 'Fast', description: 'Built for speed', icon: <Zap /> },
          { title: 'Secure', description: 'Enterprise security', icon: <Shield /> },
          { title: 'Scalable', description: 'Grows with you', icon: <Rocket /> },
        ]}
      />

      <CTASimple
        title="Ready to Start?"
        description="Join thousands of developers building with ShipKit"
        primaryCTA={{ label: 'Start Free Trial', href: '/register' }}
      />
    </>
  );
}
```
