# Installation

This guide will help you set up ShipKit on your local machine.

## Prerequisites

Before you begin, make sure you have the following installed:

- **Node.js 20+** - [Download Node.js](https://nodejs.org/)
- **npm** or **pnpm** - Package manager
- **Git** - Version control

## Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/your-org/shipkit.git my-saas-app
cd my-saas-app
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Set Up Environment Variables

Copy the example environment file:

```bash
cp .env.example .env
```

Then edit `.env` with your configuration. See [Configuration](/docs/getting-started/configuration) for details.

### 4. Set Up the Database

Initialize Prisma and create your database:

```bash
npx prisma generate
npx prisma db push
```

### 5. Start Development Server

```bash
npm run dev
```

Your app is now running at [http://localhost:3000](http://localhost:3000)!

## Troubleshooting

### npm install fails

Make sure you're using Node.js 20 or higher:

```bash
node --version
```

If you need to upgrade, use [nvm](https://github.com/nvm-sh/nvm) or download from nodejs.org.

### Database connection errors

Ensure your `DATABASE_URL` in `.env` is correct and the database server is running.

### Port 3000 already in use

Either stop the other process or use a different port:

```bash
npm run dev -- -p 3001
```
