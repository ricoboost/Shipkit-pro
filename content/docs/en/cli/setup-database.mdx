# Database Setup

The database setup command helps you configure your database connection and initialize the schema.

## Quick Start

```bash
npm run setup:db
```

## Supported Databases

### PostgreSQL

Standard PostgreSQL database, local or cloud-hosted.

```bash
npx tsx scripts/setup/setup-db.ts --provider postgresql
```

Connection string format:
```
postgresql://USER:PASSWORD@HOST:5432/DATABASE
```

### MySQL

MySQL database, local or cloud-hosted.

```bash
npx tsx scripts/setup/setup-db.ts --provider mysql
```

Connection string format:
```
mysql://USER:PASSWORD@HOST:3306/DATABASE
```

### SQLite

File-based database, perfect for local development.

```bash
npx tsx scripts/setup/setup-db.ts --provider sqlite
```

Connection string format:
```
file:./dev.db
```

<Callout type="warning">
SQLite is great for development but not recommended for production.
</Callout>

### Supabase

PostgreSQL with Supabase's additional features.

```bash
npx tsx scripts/setup/setup-db.ts --provider supabase
```

Connection string format:
```
postgresql://postgres:[PASSWORD]@db.[PROJECT].supabase.co:5432/postgres
```

Get your connection string from **Settings > Database** in Supabase dashboard.

### Neon

Serverless PostgreSQL with branching support.

```bash
npx tsx scripts/setup/setup-db.ts --provider neon
```

Connection string format:
```
postgresql://[USER]:[PASSWORD]@[HOST].neon.tech/[DATABASE]?sslmode=require
```

### PlanetScale

Serverless MySQL with branching support.

```bash
npx tsx scripts/setup/setup-db.ts --provider planetscale
```

Connection string format:
```
mysql://[USER]:[PASSWORD]@[HOST]/[DATABASE]?ssl={"rejectUnauthorized":true}
```

<Callout type="info">
PlanetScale requires `relationMode = "prisma"` in your Prisma schema.
</Callout>

## What the Setup Does

1. **Prompts for provider** - Select your database type
2. **Configures connection** - Updates `DATABASE_URL` in `.env`
3. **Updates Prisma schema** - Changes provider if needed
4. **Tests connection** - Verifies the database is reachable
5. **Runs migrations** - Executes `prisma generate` and `prisma db push`

## Command Options

Skip the migration step:
```bash
npx tsx scripts/setup/setup-db.ts --skip-migrate
```

Select provider directly:
```bash
npx tsx scripts/setup/setup-db.ts --provider postgresql
```

## Manual Setup

If you prefer manual configuration:

### 1. Update `.env`

```bash
DATABASE_URL="postgresql://user:password@localhost:5432/shipkit"
```

### 2. Generate Prisma Client

```bash
npm run db:generate
```

### 3. Push Schema to Database

```bash
npm run db:push
```

### 4. Verify with Prisma Studio

```bash
npm run db:studio
```

## Database Commands Reference

| Command | Description |
|---------|-------------|
| `npm run db:generate` | Generate Prisma client |
| `npm run db:push` | Push schema to database (no migrations) |
| `npm run db:migrate` | Run migrations in development |
| `npm run db:studio` | Open Prisma Studio |

## Troubleshooting

### Connection Refused

Make sure your database is running:

```bash
# PostgreSQL
pg_isready -h localhost -p 5432

# MySQL
mysqladmin ping -h localhost
```

### Permission Denied

Check your database user has the required permissions:

```sql
-- PostgreSQL
GRANT ALL PRIVILEGES ON DATABASE shipkit TO your_user;

-- MySQL
GRANT ALL PRIVILEGES ON shipkit.* TO 'your_user'@'localhost';
```

### SSL Required

For cloud databases, ensure SSL is enabled:

```bash
# Add to connection string
?sslmode=require
```

### Schema Out of Sync

If your schema is out of sync with the database:

```bash
# Reset and push (WARNING: destroys data)
npx prisma db push --force-reset
```
