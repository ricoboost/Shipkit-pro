# Blog System

ShipKit includes a full-featured blog system using MDX.

## Structure

```
content/
└── blog/
    ├── getting-started.mdx
    ├── how-to-use-ai.mdx
    └── release-notes.mdx
```

## Creating Posts

Create an MDX file in `content/blog/`:

```mdx
---
title: Getting Started with ShipKit
description: Learn how to build your SaaS with ShipKit
date: 2024-01-15
author: Your Name
image: /blog/getting-started.png
tags: [tutorial, getting-started]
---

# Getting Started

Your content here...
```

## Frontmatter Fields

| Field | Required | Description |
|-------|----------|-------------|
| title | Yes | Post title |
| description | Yes | SEO description |
| date | Yes | Publication date |
| author | No | Author name |
| image | No | Featured image |
| tags | No | Array of tags |

## Components

### Post Card

```tsx
import { PostCard } from '@/components/blog/post-card';

<PostCard
  title={post.title}
  description={post.description}
  date={post.date}
  slug={post.slug}
/>
```

### Blog Page

```tsx
// src/app/(marketing)/blog/page.tsx
import { getBlogPosts } from '@/lib/blog';

export default async function BlogPage() {
  const posts = await getBlogPosts();

  return (
    <div className="grid gap-6">
      {posts.map(post => (
        <PostCard key={post.slug} {...post} />
      ))}
    </div>
  );
}
```

## MDX Components

Use custom components in your posts:

```mdx
<Callout type="info">
  This is an info callout
</Callout>

<CodeBlock language="typescript">
const hello = "world";
</CodeBlock>
```
