# Organizations

ShipKit includes a complete organization/team management system.

## Features

- Create and manage organizations
- Invite team members
- Role-based access control
- Organization-level billing

## Data Model

```prisma
model Organization {
  id        String   @id @default(cuid())
  name      String
  slug      String   @unique
  members   OrganizationMember[]
  invitations OrganizationInvitation[]
  createdAt DateTime @default(now())
}

model OrganizationMember {
  id             String       @id @default(cuid())
  organizationId String
  userId         String
  role           MemberRole   @default(MEMBER)
  organization   Organization @relation(...)
  user           User         @relation(...)
}

enum MemberRole {
  OWNER
  ADMIN
  MEMBER
}
```

## API Routes

### Create Organization

```typescript
POST /api/organizations
{ "name": "My Team", "slug": "my-team" }
```

### List Members

```typescript
GET /api/organizations/:id/members
```

### Invite Member

```typescript
POST /api/organizations/:id/invitations
{ "email": "user@example.com", "role": "MEMBER" }
```

### Accept Invitation

```typescript
POST /api/invitations/:token
```

## Usage

```typescript
import { organizations } from '@/lib/organizations';

// Create organization
const org = await organizations.create({
  name: 'My Team',
  slug: 'my-team',
  ownerId: user.id,
});

// Add member
await organizations.addMember(org.id, userId, 'MEMBER');

// Check permission
const canEdit = await organizations.hasPermission(org.id, userId, 'edit');
```
