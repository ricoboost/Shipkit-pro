# Welcome to ShipKit

ShipKit is a comprehensive SaaS starter kit built with Next.js 16, designed to help you launch your SaaS product faster with complete flexibility.

  </Card>
  <Card title="Multi-Payment Providers" href="/docs/payments/overview">

## Why ShipKit?

### The Problem with Existing Boilerplates

- Lock you into one auth provider
- Lock you into one payment provider
- No AI integration ready
- Documentation is static and outdated
- Look identical with no customization

### The ShipKit Solution

A SaaS starter with complete flexibility:

- **Provider Agnostic:** Switch auth, payments, or AI with one env var
- **AI-Native:** Claude Code / Cursor understand the codebase immediately
- **Self-Documenting:** Docs auto-update when features change
- **Visually Customizable:** Design system configured through UI
- **Demo-Ready:** Working AI components to showcase immediately

## Quick Start

```bash
# Clone the repository
git clone https://github.com/your-org/shipkit.git

# Install dependencies
npm install

# Copy environment variables
cp .env.example .env

# Start the development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) to see your app.
