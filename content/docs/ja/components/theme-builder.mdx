# テーマビルダー

テーマビルダーコンポーネントは、ライブプレビューとCSSエクスポート機能を備えたアプリケーションのテーマカラーをカスタマイズするためのビジュアルインターフェースを提供します。

## 概要

主な機能:
- **5つの事前構築プリセット**: プロフェッショナルにデザインされたカラースキームから開始
- **HSLカラーピッカー**: 色相、彩度、明度コントロールで任意の色を微調整
- **ライト/ダークモード**: 両方のモードで独立してカラーをカスタマイズ
- **ライブプレビュー**: プレビューコンポーネントで変更を即座に確認
- **CSSエクスポート**: カスタムテーマをCSSとしてダウンロード

## 使用方法

### 基本実装

```tsx
import { ThemeBuilder } from '@/components/theme/theme-builder';

export default function ThemeSettingsPage() {
  return (
    <div className="container py-8">
      <h1 className="text-3xl font-bold mb-8">Customize Theme</h1>
      <ThemeBuilder />
    </div>
  );
}
```

テーマビルダーは`/admin/theme`の管理ダッシュボードでも利用できます。

## テーマプリセット

5つのプロフェッショナルにデザインされたプリセットが含まれています:

| プリセット | プライマリカラー | スタイル |
|--------|---------------|-------|
| Default | パープル | モダン、ニュートラル |
| Ocean | ブルー | プロフェッショナル、落ち着いた |
| Forest | グリーン | ナチュラル、オーガニック |
| Sunset | オレンジ | 暖かい、エネルギッシュ |
| Midnight | ディープブルー | ダーク、エレガント |

### プリセットの選択

プリセットは出発点として機能します。任意のプリセットカードをクリックして適用し、必要に応じて個々の色をカスタマイズします。

```tsx
// プリセットはsrc/lib/theme.tsで定義されています
export const themePresets = {
  default: {
    name: 'Default',
    light: { primary: '262 83% 58%', /* ... */ },
    dark: { primary: '263 70% 50%', /* ... */ },
    radius: '0.5rem',
  },
  ocean: { /* ... */ },
  forest: { /* ... */ },
  sunset: { /* ... */ },
  midnight: { /* ... */ },
};
```

## カラーグループ

カラーは4つのグループに整理されています:

### ベースカラー
- `background` - ページ背景
- `foreground` - プライマリテキストカラー
- `card` - カード背景
- `cardForeground` - カード上のテキスト

### プライマリ & セカンダリ
- `primary` - メインブランドカラー
- `primaryForeground` - プライマリ背景上のテキスト
- `secondary` - セカンダリブランドカラー
- `secondaryForeground` - セカンダリ背景上のテキスト

### UI要素
- `muted` - 控えめな背景
- `mutedForeground` - 控えめなテキスト
- `accent` - アクセントハイライト
- `accentForeground` - アクセント上のテキスト

### フィードバック & ボーダー
- `destructive` - エラー/危険カラー
- `destructiveForeground` - destructive上のテキスト
- `border` - ボーダーカラー
- `input` - 入力ボーダーカラー
- `ring` - フォーカスリングカラー

## HSLカラーピッカー

各色はHSL(色相、彩度、明度)スライダーで制御されます:

| スライダー | 範囲 | 説明 |
|--------|-------|-------------|
| H(色相) | 0-360 | ベースカラー(赤=0、緑=120、青=240) |
| S(彩度) | 0-100% | カラー強度(0=グレー、100=鮮やか) |
| L(明度) | 0-100% | 明るさ(0=黒、50=純粋、100=白) |

### なぜHSL?

HSLは一貫したカラーパレットの作成を容易にします:
- カラーの一貫性のために同じ**色相**を保つ
- 強度のために**彩度**を調整
- コントラストのために**明度**を調整(前景色は通常反対の端)

## ボーダー半径

UI要素の丸みをグローバルに制御:

| 値 | スタイル | 最適な用途 |
|-------|-------|----------|
| 0rem | シャープコーナー | ミニマル、モダン |
| 0.25rem | 控えめな丸み | プロフェッショナル |
| 0.5rem | 中程度の丸み | バランス(デフォルト) |
| 0.75rem | より丸い | フレンドリー |
| 1rem+ | 非常に丸い | 遊び心、ソフト |

## ライブプレビュー

プレビューパネルには以下が表示されます:
- **ボタン**: すべてのバリアント(primary、secondary、outline、destructive)
- **バッジ**: 異なるバッジスタイル
- **ミュートセクション**: ミュート背景上のテキスト
- **ネストカード**: カード上のカードの外観

エクスポート前にコントラストと視覚的調和を確認するために使用します。

## テーマのエクスポート

**Export CSS**をクリックしてカスタムテーマをダウンロード:

```css
/* 生成されたtheme.css */
:root {
  --background: 0 0% 100%;
  --foreground: 222.2 84% 4.9%;
  --card: 0 0% 100%;
  --card-foreground: 222.2 84% 4.9%;
  --primary: 262 83% 58%;
  --primary-foreground: 210 40% 98%;
  /* ... すべての色 */
  --radius: 0.5rem;
}

.dark {
  --background: 222.2 84% 4.9%;
  --foreground: 210 40% 98%;
  /* ... ダークモードの色 */
}
```

### エクスポートしたテーマの適用

1. エクスポートしたCSSを`src/app/globals.css`にコピー
2. 既存の`:root`と`.dark`カラー変数を置き換え
3. テーマは自動的に適用されます

## テーマの永続化

テーマは自動的にlocalStorageに保存されます:

```typescript
// テーマ選択は永続化されます
const saved = getSavedTheme();  // プリセット名または'default'を返す

// 手動保存
saveTheme('ocean');

// テーマを適用
applyTheme(themeConfig);
```

---

## プログラム的使用

テーマユーティリティを直接使用することもできます:

```tsx
import {
  themePresets,
  applyTheme,
  saveTheme,
  getSavedTheme,
  exportThemeCSS,
  type ThemeConfig,
} from '@/lib/theme';

// プリセットを適用
applyTheme(themePresets.ocean);

// ユーザー設定を保存
saveTheme('ocean');

// カスタム実装用のCSSを取得
const css = exportThemeCSS(customTheme);
```

## サーバーサイドテーマ読み込み

SSRの場合、スタイルなしコンテンツのフラッシュを防ぐために`ServerThemeLoader`コンポーネントを使用します:

```tsx
// ルートレイアウトで
import { ServerThemeLoader } from '@/components/theme/server-theme-loader';

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <head>
        <ServerThemeLoader />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

これにより、ページがレンダリングされる前に保存されたテーマを適用するスクリプトが挿入されます。

## ベストプラクティス

### コントラスト比
前景色と背景色の間に十分なコントラストを確保:
- **通常のテキスト**: 最小4.5:1のコントラスト比
- **大きなテキスト**: 最小3:1のコントラスト比

### ダークモードの考慮事項
- 単に色を反転するだけではない - ダークモードには異なる彩度レベルが必要
- ダーク背景の場合、彩度をわずかに減らす
- ボーダーが見えるままであることを確認

### ブランドの一貫性
- `primary`変数にブランドのプライマリカラーを使用
- `secondary`と`accent`は補完的に保つ
- プレビューだけでなく、実際のコンテンツでテスト
