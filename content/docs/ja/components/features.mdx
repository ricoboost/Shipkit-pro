# Featuresコンポーネント

機能セクションは、訪問者に製品の価値を理解してもらうのに役立ちます。ShipKitには、さまざまなプレゼンテーションスタイル用の6つの機能コンポーネントバリアントが含まれています。

## 利用可能なバリアント

| バリアント | 最適な用途 | 主な機能 |
|---------|----------|-------------|
| `FeaturesGrid` | 複数の機能 | レスポンシブカードグリッド |
| `FeaturesListicle` | 詳細な説明 | 番号付きリスト形式 |
| `FeaturesAccordion` | FAQスタイルのコンテンツ | 展開可能なセクション |
| `FeaturesTabs` | 機能カテゴリ | 画像付きタブインターフェース |
| `FeaturesBento` | ビジュアル紹介 | Bentoグリッドレイアウト |
| `FeaturesComparison` | プラン比較 | サイドバイサイド比較 |

## 共通Props

すべての機能コンポーネントは、これらの基本propsを共有します:

```typescript
interface FeaturesBaseProps {
  title?: string;                   // セクション見出し
  subtitle?: string;                // タイトル上の小さなテキスト
  description?: string;             // サポートテキスト
  animated?: boolean;               // アニメーションの有効/無効
  colorScheme?: ColorScheme;        // カラーテーマ
  className?: string;               // 追加のCSSクラス
}

interface FeatureItem {
  title: string;
  description: string;
  icon?: ReactNode;
}
```

interface BentoItem {
  title: string;

interface FeaturesBentoProps extends FeaturesBaseProps {
  items: BentoItem[];

### サイズオプション

| サイズ | グリッドスパン | 最適な用途 |
|------|-----------|----------|
| `default` | 1x1 | 標準機能 |
| `large` | 2x2 | ヒーロー機能 |
| `wide` | 2x1 | 長いタイトルの機能 |
| `tall` | 1x2 | 長い説明の機能 |

## FeaturesComparison

プランや製品バージョンのサイドバイサイド比較表。

### 使用方法

```tsx
import { FeaturesComparison } from '@/components/marketing/features/features-comparison';

export function PlanComparison() {
  return (
    <FeaturesComparison
      title="Compare Plans"
      columns={[
        { name: 'Starter', price: 'Free' },
        { name: 'Pro', price: '$19/mo', highlighted: true },
        { name: 'Enterprise', price: 'Custom' },
      ]}
      features={[
        { name: 'Users', values: ['1', 'Unlimited', 'Unlimited'] },
        { name: 'API Calls', values: ['1,000/mo', '100,000/mo', 'Unlimited'] },
        { name: 'Support', values: ['Community', 'Priority', '24/7 Dedicated'] },
        { name: 'Custom Domain', values: [false, true, true] },
        { name: 'Analytics', values: [false, true, true] },
        { name: 'SSO', values: [false, false, true] },
      ]}
    />
  );

```

### 追加Props

```typescript
interface ComparisonColumn {
  name: string;
  price?: string;
  highlighted?: boolean;
  cta?: { label: string; href: string };
}

interface ComparisonFeature {
  name: string;
  values: (string | boolean)[];     // Booleanはチェック/×として表示
}

interface FeaturesComparisonProps extends FeaturesBaseProps {
  columns: ComparisonColumn[];
  features: ComparisonFeature[];
}
```

## カラースキーム

すべての機能バリアントは5つのカラースキームをサポートします:

```tsx
<FeaturesGrid colorScheme="primary" {...props} />   // デフォルトブランドカラー
<FeaturesGrid colorScheme="secondary" {...props} /> // 控えめなセカンダリ
<FeaturesGrid colorScheme="accent" {...props} />    // 目を引くアクセント
<FeaturesGrid colorScheme="muted" {...props} />     // ニュートラルで控えめ
<FeaturesGrid colorScheme="destructive" {...props} /> // 警告スタイル
```

## アニメーション

すべてのコンポーネントにはスクロールトリガーアニメーションが含まれています:

```tsx
// デフォルトで有効
<FeaturesGrid animated={true} {...props} />

// パフォーマンス/アクセシビリティのために無効化
<FeaturesGrid animated={false} {...props} />
```

アニメーション機能:
- **スタガー表示**: アイテムが順番に表示される
- **フェードアップ**: 要素が上に移動しながらフェードイン
- **ビューポートトリガー**: スクロールして表示されるとアニメーション
