# クレジット付きAI搭載SaaSを構築する

このチュートリアルでは、以下を備えたAI搭載SaaSアプリケーションを構築します：

- OpenRouter経由で複数のAIモデルと統合
- クレジットベースの課金システム
- ユーザーごとの使用量追跡

## 前提条件

- [クイックスタートチュートリアル](/docs/tutorials/quickstart)を完了
- [OpenRouter APIキー](https://openrouter.ai/keys)

## 設定

```bash
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-v1-xxx
```
