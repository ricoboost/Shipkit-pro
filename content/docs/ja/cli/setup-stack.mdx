# スタックセレクター

スタックセレクターは、未使用の設定をgitで無視することで、ボイラープレートの肥大化を削減するオプションのオンボーディングステップです。すべてのAIツール設定とデプロイファイルを保持する代わりに、実際に使用するものを選択します。

## なぜ使用するのか

ShipKitには、複数のAIコーディングツールとデプロイ戦略の設定ファイルが含まれています：

| カテゴリ | ファイル | サイズ |
|----------|----------|--------|
| Claude Code | `.claude/`, `CLAUDE.md` | ~265KB |
| Cursor | `.cursor/` | ~8KB |
| Windsurf | `.windsurfrules` | ~1KB |
| Docker | `Dockerfile`, `docker-compose*.yml`, `nginx/` | ~15KB |

Claude Codeのみを使用してVercelにデプロイする場合、残りを無視してプロジェクトをクリーンに保つことができます。

## スタックセレクターの実行

### インタラクティブモード

```bash
npm run setup:stack
```

これにより、インタラクティブなプロンプトが開きます：

```
スタックセレクター（オプション）

このステップは、未使用の設定を無視することで
ボイラープレートの肥大化を削減します。スキップしてすべてのオプションを保持できます。

どのAIコーディングツールを使用しますか？（カンマで複数選択）
   [1] Claude Code
   [2] Cursor
   [3] Windsurf
   [a] すべて / すべて保持（デフォルト）
   [s] このステップをスキップ

選択: 1,2

どのデプロイ戦略を使用しますか？
   [1] Vercel（Next.jsに推奨）
   [2] Docker / セルフホスト
   [s] このステップをスキップ

選択: 1
```

### 現在の設定を確認

```bash
npm run setup:stack -- --list
```

### すべてのファイルを復元

気が変わった場合、無視されたすべてのファイルを復元します：

```bash
npm run setup:stack -- --restore
```

## Gitで無視されるもの

選択に基づいて、スタックセレクターは`.gitignore`にエントリを追加します：

### AIコーディングツール

| ツール | 無視されるファイル |
|--------|-------------------|
| Claude Code | `.claude/`, `CLAUDE.md` |
| Cursor | `.cursor/` |
| Windsurf | `.windsurfrules` |

**注意:** AIツールが選択されている場合、`AGENTS.md`は保持されます。

### デプロイ戦略

| 選択 | 無視されるファイル |
|------|-------------------|
| Vercel | `Dockerfile`, `docker-compose.yml`, `docker-compose.dev.yml`, `.dockerignore`, `nginx/` |
| Docker | なし（すべてのDockerファイルが保持されます） |

**注意:** `.github/`ワークフローは両方の戦略で常に保持されます。

## 設定ファイル

スタックセレクターは選択を追跡するために`.stack-config.json`を作成します：

```json
{
  "selectedAt": "2024-12-13T10:30:00.000Z",
  "codingTools": ["claude", "cursor"],
  "deployment": "vercel",
  "gitignored": [
    ".windsurfrules",
    "Dockerfile",
    "docker-compose.yml",
    "docker-compose.dev.yml",
    ".dockerignore",
    "nginx/"
  ]
}
```

このファイルにより、`--restore`コマンドが正しく機能します。

## セットアップウィザードとの統合

スタックセレクターは、フルセットアップウィザードを実行する際の最初のオプションステップです：

```bash
npm run setup
```

ウィザードのフローは：

1. **スタックセレクター**（オプション）- ツールを選択
2. 環境変数（必須）
3. データベース（必須）
4. 認証（必須）
5. 支払い（オプション）
6. AIプロバイダー（オプション）
7. 管理者ユーザー（オプション）

## ベストプラクティス

### スタックセレクターを使用する場合

- 特定のツールで新しいプロジェクトを開始する場合
- ボイラープレートをクローンした後のクリーンアップ
- ファイルエクスプローラーのノイズを削減

### スキップする場合

- 複数のAIコーディングツールを評価中
- デプロイ戦略を変更する予定
- 混合ツール設定のチームで作業

## トラブルシューティング

### 選択後もファイルが表示される

スタックセレクターは`.gitignore`にファイルを追加するだけで、削除しません。ファイルは作業ディレクトリに残りますが、gitにコミットされません。

### 代わりにファイルを削除したい

スタックセレクターを実行した後、無視されたファイルを手動で削除できます：

```bash
# 何が無視されているか確認
npm run setup:stack -- --list

# 必要に応じて手動で削除
rm -rf .cursor .windsurfrules
```

### 復元が機能しない

`.stack-config.json`が存在することを確認してください。削除された場合、`.gitignore`からスタックセレクターセクションを手動で削除する必要があります。
