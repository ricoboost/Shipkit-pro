# ウェイトリスト & ページビルダー

ShipKitには、カスタムランディングページを作成するためのビジュアルページビルダーを備えた完全なウェイトリスト管理システムが含まれています。

## 概要

ウェイトリスト機能でできること：

- ローンチ前にメール登録を収集
- コード不要で美しいランディングページを作成
- タグとセグメンテーションで登録者を管理
- 登録者データをCSVでエクスポート
- ウェイトリストモードを有効にして新規登録をリダイレクト

## ウェイトリストモードの有効化

### 管理パネルから

1. **Admin** > **設定** > **Feature Flags** に移動
2. **ウェイトリストモード**を有効にする
3. 新規ユーザーはサインアップの代わりにウェイトリストページにリダイレクトされます

### コードから

```typescript
import { admin } from '@/lib/admin';

// ウェイトリストモードを有効にする
await admin.toggleFeatureFlag('waitlistMode', true);

// ウェイトリストモードを無効にする
await admin.toggleFeatureFlag('waitlistMode', false);
```

## ページビルダー

ビジュアルページビルダーでカスタムウェイトリストランディングページを作成できます。

### エディタへのアクセス

**Admin** > **Waitlist** > **ページ編集** に移動するか、直接 `/admin/waitlist/editor` にアクセスします。

### 利用可能なセクション

#### ヒーローセクション

メインヘッダーセクション：
- バッジテキスト（例：「Coming Soon」）
- ヘッドラインとサブヘッドライン
- 登録フォームまたはCTAボタン
- オプションのヒーロー画像

#### 機能グリッド（Bento）

製品機能のショーケース：
- 2、3、または4カラムレイアウト
- アイコン付きの機能カード
- カスタマイズ可能な背景

#### 使い方

ステップバイステップのプロセス説明：
- アイコン付きの番号付きステップ
- 水平または垂直レイアウト
- カスタムタイトルと説明

#### フッター

ページフッター：
- 著作権テキスト
- ナビゲーションリンク
- ソーシャルメディアアイコン

### セクションのカスタマイズ

セクションをクリックして選択し、右サイドバーで：

- **背景**: 単色、グラデーション、または画像を設定
- **スペーシング**: パディングとマージンを調整
- **表示**: セクションの表示/非表示
- **カスタムCSS**: カスタムスタイルを追加

### コンテンツの編集

- テキストをクリックしてインライン編集
- タイポグラフィを変更（サイズ、ウェイト、色、配置）
- ボタンテキストとスタイルを更新
- フォームのプレースホルダーと成功メッセージをカスタマイズ

### 公開

1. **保存**をクリックして変更を保存
2. **公開**をクリックしてページを公開
3. `/waitlist` でページをプレビュー

## 登録者の管理

### 管理ダッシュボード

**Admin** > **Waitlist** で登録者ダッシュボードにアクセス。

#### 統計

- **総登録者数**: すべての登録
- **確認済み**: 確認されたメール
- **保留中**: 確認待ち
- **解除済み**: オプトアウト
- **今週**: 最近の登録

#### フィルタリング

登録者をフィルタリング：
- メール検索
- ステータス（確認済み、保留中、解除済み）
- ソース（waitlist、footer、popup）
- タグ

### 一括操作

複数の登録者を選択して：
- セグメンテーション用のタグを追加
- リストから削除
- CSVでエクスポート

### データのエクスポート

**CSVエクスポート**をクリックして登録者データをダウンロード。

## 登録フォーム

### 埋め込みフォーム

任意の場所に登録フォームを追加：

```tsx
import { SubscribeFormBlock } from '@/components/waitlist-builder/blocks/subscribe-form-block';

<SubscribeFormBlock
  block={{
    id: 'form-1',
    type: 'subscribe-form',
    placeholder: 'メールアドレスを入力',
    buttonText: 'ウェイトリストに参加',
    successMessage: '登録ありがとうございます！',
    source: 'homepage',
    tags: ['early-access'],
  }}
/>
```

## APIリファレンス

### 登録

```typescript
POST /api/newsletter/subscribe

// リクエスト
{
  "email": "user@example.com",
  "source": "waitlist",
  "tags": ["early-access"]
}

// レスポンス
{
  "success": true,
  "isNew": true,
  "confirmed": false
}
```

### 登録解除

```typescript
POST /api/newsletter/unsubscribe

// リクエスト
{ "email": "user@example.com" }

// レスポンス
{ "success": true }
```

## ライブラリ関数

```typescript
import { newsletter } from '@/lib/newsletter';

// ソースとタグで登録
await newsletter.subscribe({
  email: 'user@example.com',
  source: 'waitlist',
  tags: ['early-access', 'beta'],
});

// 登録者統計を取得
const stats = await newsletter.getStats();

// 登録者にタグを追加
await newsletter.addTags('user@example.com', ['vip']);

// CSVにエクスポート
const csv = await newsletter.exportCSV({
  confirmedOnly: true,
  tag: 'early-access',
});
```

## ベストプラクティス

1. **意味のあるタグを使用** - ソース、関心、またはキャンペーンで登録者をセグメント化
2. **確認メールを設定** - 高品質なリストのためにダブルオプトインを有効に
3. **ページをカスタマイズ** - ページビルダーでブランドに合わせる
4. **統計を監視** - コンバージョン率とエンゲージメントを追跡
5. **定期的にエクスポート** - 登録者リストをバックアップ
