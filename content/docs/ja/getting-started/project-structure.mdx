## 重要な概念

### ルートグループ

ルートグループ `(groupName)` はURLに影響を与えずにルートを整理します:

- `(marketing)` - `/`, `/pricing`, `/blog`の公開ページ
- `(auth)` - `/login`, `/register`の認証ページ
- `(dashboard)` - `/dashboard`, `/settings`のユーザーページ
- `(admin)` - `/admin`の管理ページ

### プロバイダー抽象化

各主要機能は統一されたインターフェースを使用します:

```typescript
// lib/auth/index.ts が統一インターフェースをエクスポート
export const auth = getAuthProvider(); // 設定されたプロバイダーを返す

// 使用方法はプロバイダーに関係なく同じ
const session = await auth.getSession();
```

### 型安全性

すべてのAPIはZodを検証に、oRPCを型安全なエンドポイントに使用します:

```typescript
// 完全に型付けされたAPI呼び出し
const result = await rpc.users.getProfile.query();
```
