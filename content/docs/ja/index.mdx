# ShipKitへようこそ

ShipKitは、Next.js 16で構築された包括的なSaaSスターターキットで、完全な柔軟性を持ってSaaS製品をより速くローンチできるよう設計されています。

## なぜShipKit？

### 既存ボイラープレートの問題点

- 単一の認証プロバイダーに縛られる
- 単一の決済プロバイダーに縛られる
- AI統合の準備がない
- ドキュメントが静的で古い
- カスタマイズなしで同じ見た目

### ShipKitソリューション

完全な柔軟性を持つSaaSスターター：

- **プロバイダー非依存:** 環境変数1つでauth、決済、AIを切り替え
- **AIネイティブ:** Claude Code / Cursorがコードベースを即座に理解
- **自己文書化:** 機能が変更されるとドキュメントが自動更新
- **視覚的にカスタマイズ可能:** UIでデザインシステムを設定
- **デモ準備完了:** すぐに紹介できる動作するAIコンポーネント

## クイックスタート

```bash
# リポジトリをクローン
git clone https://github.com/your-org/shipkit.git

# 依存関係をインストール
npm install

# 環境変数をコピー
cp .env.example .env

# 開発サーバーを起動
npm run dev
```

その後 [http://localhost:3000](http://localhost:3000) を開いてアプリを確認してください。
